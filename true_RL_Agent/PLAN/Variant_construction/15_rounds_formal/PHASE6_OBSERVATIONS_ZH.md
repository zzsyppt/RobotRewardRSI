- **搜索覆盖窄于哈希多样性。** `16` 个有效候选中 `13` 个仍属于 contact/clearance/impact/posture 一族，只有 G3-A、G4-A、G9-B 三个属于 progress-state 一族；`9/16` 使用 bottom-origin 的 `base_height`。Gen7、Gen8 的两条 lane 虽通过 sibling canonical exclusion，却在概念上同时落入同一 clearance/contact 家族。G9-A 是对接触 onset/force 的合理局部迭代；G9-B 不是 exact repeat，但因 F46 所述记忆缺口盲重访了旧 progress-state 概念。`base_height`、`goal_progress_fraction` 和 contact 的坐标/因果误读已归 O2/F41/F43，不在此重复建项。
- **plateau 的首因是候选机制质量与概念收缩，不是 selector/formal 接线错误。** Gen3 current-best 的 public_dev 为 `J_primary=0.962736, F_scalar=0.832314, F_c1=F_c2=J_ID=1`。其后所有真实非零候选在 public_dev 的 `F_scalar` 都低于 `0.832314`（约 `0.505952–0.777585`）；G6-A 只是因为新增项全程零而精确复现 parent。故截至 Gen8 没有一个新机制在公开主瓶颈上真实超过 head。
- **目标饱和与材料性压缩是重要的结构性阻力，但不是错误接受门。** 在 `F_c1=F_c2=J_ID=1` 不变时，`J_primary=7/9+(2/9)F_scalar`；Gen3 的 human-only `J_accept=0.953588` 对应冻结 headroom 门 `0.2×(1-J)=0.009282`，单靠 `F_scalar` 至少需提高约 `0.041771` 才能过门。Gen7-B 是 Gen3 后最好的 human-only 正增量，也只有 `+0.002112 J_primary`，远低于门槛。高基线压缩了可测余量，但当前失败不是 hidden acceptance bug。
- **split/样本噪声只解释小幅 selector reversal，不能解释 plateau。** 被 public_dev 选中的 G5-A/G6-B/G7-B/G8-A 相对 parent 的 `dev→accept` 增量分别为 `-0.022457→-0.016975`、`-0.012162→+0.001151`、`-0.014048→+0.002112`、`-0.018957→-0.023712`。中间两次确有符号反转，但幅度仅 `0.1–0.2` 个百分点，仍远低于 `0.928` 个百分点的冻结材料性门；不能据此把失败归因为噪声，也不得把 private split 回灌 provider。
- **反馈确实避免了一部分浪费，但长期概念记忆不足。** 五次 exact/no-delta 被 GPU 前挡下；G6-A 的零作用项被 runtime-effect gate 正确排除；Gen4-B 的 `height_scan` 失败后未再重用同一输入签名。另一方面，负卡只公开最近两条、no-selection 代只留空壳且 experiment memory 每代只索引 selected/formal trial，导致跨多代的概念重访缺少旧结果对照，具体见 F46。该缺口不影响当前判决权威性，也不授权修改正在运行的 Gen9。

截至本审计点没有发现需要停止当前实验的新 blocker；继续只以权威 runtime activation、public_dev selector 和 formal 结果判断 Gen9，训练曲线不参与候选排名。
