Exact code-level difference: exactly one named mechanism is added, a new reward callable tilt_brake defined as -(sum of squared planar angular rate) / (1 + 8 * (roll^2 + pitch^2)), weighted +1.0. All other anchor mechanisms (upright_height, stationary_v3, tilt_damping, joint_pose, action_rate, fall) keep their original callables, weights and mechanisms; no term is removed and no diagnostic or schedule is introduced. Hypothesis: the anchor's tilt_damping term is the product of squared tilt and squared angular rate, so its gradient vanishes quadratically as tilt approaches zero; a robot that has just been pushed and is still nearly upright receives almost no explicit incentive to arrest the angular velocity that will grow into the tilt excursion, which is where the high-stratum and repeated-push losses and the side/backward falls sit. The new term is a tilt-normalized angular-rate brake: it is non-positive, vanishes only when the planar angular rate is zero, and its magnitude is largest at small tilt, so it supplies a recovery gradient exactly in the near-upright phase where the anchor's product term is silent, while the denominator 1 + 8 * tilt attenuates it once the robot is already tilted so it does not fight the large postural corrections that strong pulses require. Because the term is bounded by the angular rate itself and is attenuated by tilt, it cannot dominate the transient regime the way a fixed quadratic penalty would. Expected outcome: fewer tilt-phase recoveries lost to unchecked angular velocity, so high and repeated strata improve while low and medium strata are preserved because a quiet upright stance already has near-zero angular rate and pays almost nothing. Closest rejected prior is the sibling push_recovery_tilt_rate_brake_v6 (public_dev delta -0.1875, qualified_not_selected), which added a tilt_rate_brake term; this candidate differs at the code level by normalizing the squared planar angular rate by 1 + 8 * tilt instead of using the raw rate, so the brake is strongest near upright and fades as tilt grows, rather than applying uniformly across the whole tilt range.
