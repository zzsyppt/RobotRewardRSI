The reference upright_height term rewards being near nominal height and upright through a bounded exponential, but it is a pure state potential: it provides no gradient that couples tilt magnitude to angular rate, so a robot that is already tilting while rotating has no explicit incentive to arrest the rotation before the tilt grows into a fall. This candidate changes exactly one named canonical prompt-visible component mechanism relative to the reference: it adds a single new reward callable, tilt_damping, defined as the negative product of the squared tilt magnitude (roll^2 + pitch^2) and the squared planar angular rate (base_ang_vel_scaled[:, :2]^2 summed), weighted +1.0. Because the term is non-positive and vanishes whenever either tilt or angular rate is zero, it penalizes only the joint condition of being tilted while rotating, supplying a recovery gradient that pushes the policy to kill angular velocity during the tilt excursion rather than only to return to nominal height.
