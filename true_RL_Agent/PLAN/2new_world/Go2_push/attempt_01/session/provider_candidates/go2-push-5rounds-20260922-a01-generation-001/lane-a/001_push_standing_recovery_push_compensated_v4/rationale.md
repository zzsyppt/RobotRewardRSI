Reference stationary_v3 penalizes total measured planar velocity, including the task controller injected push increment. That increment is not a policy outcome, so the penalty adds uncontrollable negative reward and can discourage recovery motion. This candidate keeps every other mechanism identical and changes only the stationary damping term: it computes the public push increment in the same scaled world-frame units and subtracts it before damping. Residual post-push motion is still penalized on subsequent steps. Hypothesis: removing push-induced velocity from the damping penalty reduces reward noise and improves complete-sequence recovery and the fresh stable dwell.
