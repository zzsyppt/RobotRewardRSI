Reference anchor push_standing_recovery_stationary_reference_v3 uses stationary_v3, which rewards low base velocity unconditionally and therefore fights the recovery response right after an injected push. This candidate changes exactly one component mechanism: it replaces stationary_v3 with stationary_push_compensated, which keeps the same bounded planar/angular damping core but subtracts 0.5 * push_active * |push_vec_public| only on the current step of a verified injected push. The gate uses only the prompt-visible push_active and push_vec_public fields, so it never fires on autonomous motion and never latches through recovery. upright_height, joint_pose, action_rate, and fall are preserved unchanged from the anchor; no diagnostics or schedules are added.
