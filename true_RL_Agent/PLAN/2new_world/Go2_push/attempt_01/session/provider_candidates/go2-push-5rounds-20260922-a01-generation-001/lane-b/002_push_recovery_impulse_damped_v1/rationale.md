Reference anchor push_standing_recovery_stationary_reference_v3 uses stationary_v3, which rewards low base velocity unconditionally and therefore fights the recovery response right after an injected push. This candidate replaces stationary_v3 with impulse_damped_velocity: the same bounded planar/angular damping core, but with an explicit push_active-gated term that subtracts 0.5 * |push_vec_public| only on the current step of a verified injected push. The gate uses only the prompt-visible push_active and push_vec_public fields, so it never fires on autonomous motion and never latches through recovery. upright_height, joint_pose, action_rate, and fall are preserved unchanged from the anchor; diagnostics and a neutral reward_weight_scale schedule are added for public feedback.
