It is the one-sided derivative of the lateral tilt energy: it charges a state only while the sideways tilt magnitude is growing, it is exactly zero while the base sits inside the nominal stance band, and it is exactly zero whenever roll * roll_rate is negative, that is while the base is already rolling back toward level. The anchor prices the lateral state with three level quantities, namely the squared tilt branch inside upright_recovery, the linear roll brace, and the symmetric lateral speed term; none of them separates a still-growing topple from an already-decaying one, so at the tipping onset the only lateral gradient available scales with the current roll rather than with the diverging rate that decides whether the fresh stable dwell is reached before the base passes the point of no return. The new term supplies exactly that missing one-sided rate gradient, which shortens the window in which a repeated-pulse sequence can re-topple a base that is still rolling, and it touches no translational channel, so it cannot brake the lateral stepping strategy that the accepted speed terms already bound, which is the failure mode of the refuted speed-damping route.
