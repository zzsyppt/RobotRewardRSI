Closest prior program: push_recovery_nonsaturating_stance_v1, the accepted current best (public_dev mean 0.8802, dominant failure fall_dominated with 15 fall_side and 1 fall_forward). Sole mechanism change: the upright_recovery kernel gains a tilt-aware coupling term; every other term, weight, sign, clip, and the empty schedule and diagnostic lists are preserved. The anchor's kernel is 1 - (5*e + e*e + 2*u + 2*u*u) with e = clamp(abs(base_height_relative - 1) - 0.05, 0) and u = clamp(roll*roll + pitch*pitch - 0.01, 0). Its height and tilt branches are additive and independent, so a base that is simultaneously low and tilted receives the same slope as a base that is only low or only tilted; the residual side falls occur when the base is both sunk and rolled, where the anchor's pull-up slope is weakest relative to the destabilizing torque. The replacement adds 4*e*u to the penalty, so the gradient with respect to height grows with tilt and the gradient with respect to tilt grows with height. Near the goal (e = 0 or u = 0) the coupling vanishes and the value is identical to the anchor, so the low and medium strata that already recover keep the same signal. Far from the goal the coupling adds up to about 4 per unit of e*u, which at weight 3.0 roughly doubles the effective pull-up slope for a base that is both sunk and rolled, directly targeting the fall_side mode without changing the success definition.
