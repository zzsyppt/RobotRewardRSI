Reference candidate push_standing_recovery_stationary_reference_v3 uses stationary_v3, an unconditional velocity penalty that is strongest exactly when the robot needs corrective motion after large pushes. This replacement keeps every other reference reward mechanism unchanged and replaces stationary_v3 with recovery_damping: a stability-gated velocity damping term that scales damping down when tilt or height error is large, so recovery motion is not suppressed, and adds a low-height low-speed collapse guard that penalizes a quiescent crouched state after the push sequence. The mechanism targets the public high and repeated strata failures and the dominant height_collapse mode by allowing transient recovery motion while still shaping a tall, low-velocity stable dwell.
