The reference program stationary_v3 term grants full stillness reward regardless of base height or orientation, so a robot that collapses and remains still can collect the stationary bonus, and the same term penalizes the leg motion needed to recover from a large push. Replace only that mechanism with stable_damping: a posture-gated stillness reward that multiplies the original velocity penalty by smooth height and projected-gravity gates. The gates are zero when the base is low or tilted, so collapsed postures cannot collect the bonus, while recovery motion during the acute phase is not penalized. This targets the observed height-collapse failure mode and the high/repeated push strata without changing other reward mechanisms, weights, or task protocol.
