The reference standing-recovery program reaches 0.734 public-dev score but fails mostly on high and repeated perturbations, with height_collapse the largest failure category (26 of 192). The reference only gives a positive exponential height reward, so a collapsed but non-terminated posture is not directly penalized. This candidate preserves every reference reward term and adds one bounded height-collapse penalty: below 0.75 normalized base height it charges the squared height deficit, amplified by tilt. The intended mechanism is an asymmetric, morphology-scaled posture cost that makes severe crouching unattractive while leaving the unchanged upright, damping, joint, action-rate and fall terms to shape normal recovery.
