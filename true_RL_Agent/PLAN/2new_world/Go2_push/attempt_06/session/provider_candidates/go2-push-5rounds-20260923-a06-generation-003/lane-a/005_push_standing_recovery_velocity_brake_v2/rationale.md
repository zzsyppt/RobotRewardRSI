Anchor and evidence. Authoring anchor: accepted current-best push_standing_recovery_height_barrier_v1 (public_dev mean 0.78125), whose one-sided downward-modulated height barrier addressed the height_collapse-dominated failure reported for the closest prior evaluated candidate push_recovery_height_hinge_v4 (public_dev mean 0.703125). The latest nonaccepted candidate push_standing_recovery_stance_barriers_v2 (public_dev mean 0.8072916666666666, formal_rejected) added a one-sided tilt barrier on top of the anchor height barrier; its public-dev failure breakdown still shows 28 height_collapse, 5 fall_side, 2 fall_backward, 2 not_recovered, with the high push stratum at 22/48. The residual failure mass is therefore still dominated by height collapse and side/backward falls that occur while the base is already translating or rotating: the exponential stance channel and the height barrier both act on posture, but neither directly damps the pre-terminal base velocity that carries the robot into the fall. Exact code-level difference from the anchor: exactly one RewardTerm callable is replaced, stationary_v3 becomes stationary_brake. The nominal stance reward exp(-4*(roll^2 + pitch^2) - 4*(base_height_relative - 1)^2) and the full height barrier 4*max(0.8 - base_height_relative, 0)^2*(1 + min(max(-v_z, 0), 2)) with v_z = base_lin_vel_scaled[2] are preserved unchanged, so nominal standing, mild crouch, and downward-motion risk are shaped exactly as in the anchor. The new callable keeps the same saturating planar and angular speed cores and the same 1.0 - 0.25*(planar_penalty + angular_penalty) shape, and adds exactly one mechanism: a one-sided, non-saturating brake on the pre-terminal base velocity magnitude, brake = 0.5*max(planar_speed - 1.0, 0) + 0.5*max(angular_speed - 1.0, 0), subtracted from the stationary output. Every other callable, weight, diagnostic and schedule is identical to the anchor. Mechanism hypothesis: below the saturating cores (planar_speed <= 1.0 and angular_speed <= 1.0) the brake is exactly zero, so nominal stance and ordinary recovery-step transients are untouched; above that band the brake contributes a persistent linear gradient precisely where the saturating cores have flattened to a constant, giving policy updates a usable pre-terminal signal to arrest base translation and rotation before the -20 fall term fires only at termination. This is a velocity-domain brake, deliberately distinct from the tilt-domain barrier of push_standing_recovery_stance_barriers_v2 and from the height-domain barrier of the anchor, so it is not a repeat of either evaluated program. Reward shaping cannot change pulse verification, timing, or the success definition, and this candidate changes none of them.
