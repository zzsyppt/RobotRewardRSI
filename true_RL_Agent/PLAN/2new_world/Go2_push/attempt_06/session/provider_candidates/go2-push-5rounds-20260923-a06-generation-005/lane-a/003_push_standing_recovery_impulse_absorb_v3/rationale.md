The new callable changes exactly one mechanism relative to the anchor: the height barrier becomes two-sided. The downward-modulated low-height barrier 4*max(0.8 - base_height_relative, 0)^2*(1 + min(max(-v_z, 0), 2)) with v_z = base_lin_vel_scaled[2] is preserved unchanged, and a mirrored upward-modulated high-height barrier 4*max(base_height_relative - 1.2, 0)^2*(1 + min(max(v_z, 0), 2)) is added, so both crouch-collapse and over-extension are shaped. The one-sided multiplicative impulse-absorption barrier built from three bounded saturating risk factors, tilt_risk = tilt/(tilt + 0.25) with tilt = roll^2 + pitch^2, speed_risk = |v_xy|/(|v_xy| + 0.5) using world-frame base_lin_vel_scaled[:, :2], and spin_risk = |omega|/(|omega| + 1.0) using base_ang_vel_scaled, combined as impulse_risk = tilt_risk * speed_risk * spin_risk and subtracted as 2.0 * impulse_risk, is preserved unchanged, with the stance term output bounded below by clip_min = -3.0. Every other callable, weight, diagnostic and schedule is identical to the anchor. Mechanism hypothesis: the anchor and the additive-tilt sibling both apply their pre-fall risk channels as separable one-dimensional penalties, so a robot that is simultaneously tilted, translating, and rotating still receives only the sum of individually bounded terms and the hardest high-stratum episodes remain height_collapse-dominated. The multiplicative conjunction is near zero whenever any single risk factor is small, so nominal stance, mild crouch, and ordinary recovery-step transients are untouched, but it grows sharply only in the joint tilt-plus-translation-plus-rotation regime that immediately precedes the observed collapse, giving policy updates a usable pre-terminal gradient concentrated exactly on the hardest episodes. The replaced callable deliberately does not include planar or angular velocity damping as standalone terms (that stays in the unchanged stationary_v3 callable), so the new mechanism is a conjunctive pre-fall risk channel rather than a fused stationary-recovery composite.
