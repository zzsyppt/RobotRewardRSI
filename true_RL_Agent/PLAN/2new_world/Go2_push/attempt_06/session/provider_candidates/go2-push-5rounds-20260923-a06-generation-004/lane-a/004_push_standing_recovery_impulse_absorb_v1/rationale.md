Reference current-best push_standing_recovery_height_barrier_v1 (public-dev mean 0.78125) has residual failures dominated by height_collapse (28/192) and a weak high stratum (22/48), i.e. after the largest pulses the base still collapses or drifts instead of settling. Its stationary_v3 term is a piecewise-linear speed penalty that is exactly flat once planar_speed exceeds 0.08 m/s and angular_speed exceeds 0.5 rad/s, so it provides no gradient during the large post-push excursion that precedes those failures. This candidate changes exactly one component mechanism: the stationary_v3 RewardTerm callable is replaced by impulse_absorb. The new callable forms a single bounded excitation scalar from morphology-scaled planar speed, angular speed, tilt, and height deficit, and returns its negative square, so the penalty grows smoothly and keeps a usable gradient throughout the large-excursion regime while remaining near zero at the nominal stance. The upright_height_barrier callable, the joint_pose, action_rate, and fall callables, and every weight are preserved unchanged. The mechanism-level difference from the rejected tilt_arrest_v7 is that this is a velocity/height excitation absorber, not a tilt barrier, and it does not duplicate the height barrier already present in upright_height_barrier.
