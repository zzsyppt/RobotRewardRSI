## 唯一问题与条件

现有 Go2 在 D 的 ×2 协议下 dev 为192/192。使用同一 checkpoint、同一后端、同一观测/动作、原三个 dev seed（10042、10043、10044，每个64环境），对照原双推与短间隔双推。仅 repeated 的第二次施扰时刻改变，另外144个单推episode为不变对照。

- 时间尺度 T=sqrt(L/g)，Go2 L=0.4m，T≈0.20193s。采用绝对时刻向上取整：第一推 ceil(5T/dt)=51步，第二推从 ceil(17T/dt)=172步改到 ceil(6T/dt)=61步；dt=0.02s，实际间隔从2.42s缩短到0.20s。
- 两次速度增量均保持原 medium 幅值，约1.18855m/s；第二方向保持第一方向+π/2。不是增大力度、改变施力位置或改成真实外力。
- 第二推发生在第一推不可能完成原1.5T稳定驻留之前；不声称那一刻每条轨迹均仍物理失稳。时刻预定，不按策略表现触发。
- 序列成功：两次施扰确实发生且验证有效；最后一次注入后的下一物理样本起，重新累计连续稳定驻留，在ceil(8T/dt)=81步窗口内达到ceil(1.5T/dt)=16步；全程未跌倒/越界且原30T episode末态稳定。首推驻留不能借用；不报告“两次独立恢复”。稳定、跌倒、越界阈值全部沿用原协议。
- 第一推后提前失败仍计入原48个repeated分母，不因缺第二推删除样本。未提前失败但缺计划施扰属于接线无效。
