# G：Go2 外力强度曲线与成功判定视觉复核

2026-09-22。用户授权按讨论进行研究，并结合仿真视觉排除成功率满分来自误判。本轮为公开开发诊断，不是新 reference 资格。F 的原始证据和冻结源码保留。

## 事前固定的研究范围

复用 Go2 D checkpoint（SHA256 `1495390b192b913432b8472cb150e2db07fdc2eb811eeabe4ab87c577b24e0ff`），不训练。F 的 1×、192 episode 作为已有基线；只新增 1.5×、2× 两档，各沿用三个公开 dev seed 10042/10043/10044、每 seed 64 环境，新增统计样本共 384。倍率仅乘实际外力，不改变质量、方向、作用点、0.22 秒时长、双推时序、跌倒/越界阈值或恢复窗口/驻留标准。保持每个环境的名义冲量随倍率同比增加；不要求根速度增量与冲量除以质量相等。

两档完成即停止，不根据结果加第三档、不搜索作用点、不缩短成功期限。报告每档总体、三个 seed、四个层及全部失败类别。G1 不增加难度，仅允许对 F 中一个已经失败的样本录像，作为判别失败的视觉对照。0 训练、0 accept/sealed、0 provider。

## 成功判定与视觉

独立审阅评分器与产品终止链路；从实际 PhysX 力、reset 前根位姿/速度重算全部首 episode。检查力确实送达、脉冲外清零、首 episode 时间连续、未把 reset 后站立误算恢复，以及每次推力结束后完整稳定驻留和末态稳定。成功仍要求全程无原协议跌倒/高度塌落/越界，视觉不另创接受门。

录像样本按以下确定规则在统计完成后自动选择，平局按 seed/env 排序：

1. F 的 1×：事件恢复延迟最大的成功样本。
2. 每个新增档：恢复延迟最大的成功样本（若有）；全程最大绝对 roll/pitch 的不同成功样本（若有）；最早物理跌倒/高度塌落样本（若有，否则取最早非跌倒失败样本）。每档最多三条；同时数值审阅最低高度等极值，不只挑选漂亮姿态。
3. G1 F：最早物理跌倒/高度塌落样本一条。

上限八条录像；每次重放使用原 seed 的全部 64 环境、原 checkpoint/质量随机化/策略，只显示所选机器人。录像逐 control 在物理更新后、termination/reset 前采帧，保留最后失败帧。只重放选中的 seed，录像样本不计入新的统计分母。记录每帧 step、原始状态及实际施力，与无渲染原始轨迹和判定比较。渲染若造成差异，诚实记录，不能把录像当作原轨迹的严格复现。

检查完整原生视频和推力前、推力末、最差姿态、判定恢复/失败、末态关键帧。必要时将姿态、根高度、水平/角速度和恢复阈值叠加为可读注释，原视频另存。视频只能检视有限样本，不宣称证明所有物理状态或指标语义绝对正确。

## 实施、边界与停止

仅扩展 PLAN 内现有诊断入口，复用训练环境、策略加载、原生渲染/编码和 GPU lease/owned process；产品代码与正式协议不变。新定义显式包含 force_scale 并冻结源码、checkpoint、后端与参数身份；旧 F 身份不重写。每个统计/录像作业上限 1800 秒，技术失败原样留存，修正后记录新执行身份，不靠重试筛选成绩。

先 CPU 预检/评分回归并冻结，再执行两个统计作业；独立离线复算、选样并冻结录像列表，再录像、逐帧对应与视觉审阅。最终记录结果、指标适用边界与后续建议。验证既有 reference 和完整 15 rounds checkpoint 未变化、进程退出与 GPU 释放。若有判别错误，先定位其真实所有权并修复，再讨论难度；若未发现，也不以诊断成功替代 P6 的正式资格闭合。
