## 对下一步边界的修正

执行前的 GO2_TASK_DOMAIN_REVIEW_ZH.md 已按原字节保存在本次证据包。复核总计划和当前实现后，需要收紧其中关于“连续扰动”的推论：**原计划没有明确要求恢复窗口重叠；当前 repeated 的两次充分间隔恢复也是事前冻结的多次扰动定义。** 恢复中再次受推是合理的可选任务域研究，不能为了 Go2 饱和，把它重新包装成一项既有接线缺陷或本轮必修项。

当前两事件实现分别持有自己的恢复期限：第一事件已恢复时不因第二推撤销；窗口重叠时，同一段稳定驻留可能同时满足两事件；第二推也不会延长第一期限。因此仅删除“不重叠”校验，不能自然得到“最后一次扰动后整段序列恢复”的语义。这一差别归 Push 所有，无理由引入共享序列框架。

目前没有依据修改成功定义、增加足接触/动作幅度限制、降低训练预算或扩展 C/D 强度网格。工程和已检查物理证据没有暴露尚待修复的阻断项，未完成的是 Go2 事前的 reference 余量门。三卷是同一物理域中的新样本验证，不是三个物理 OOD 域。

## 需要明确的研究方向

如果后续确实要研究恢复中再次受推，建议把目标写为“预定双推序列结束后，在一个完整恢复窗口内重新稳定；全程不得跌倒或越界”，而不是要求两次相互独立的恢复动作。新的 Push 协议应事前固定时间分布、序列计数、全训练覆盖、独立验证 cohort、有限预算和停止规则；允许复用现有两事件槽及共享 harness，但旧 C/D 结果和门保持原义。该目标不承诺 reference 一定进入 [0.2,0.9]。
