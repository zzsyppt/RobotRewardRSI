## 任务域缺口与后续判断

当前train覆盖四层、完整方向与独立双事件方向；dev/accept/sealed共享完整物理协议，只换随机seed/方向相位。它们证明的是既定任务域中的新样本表现，不是三个物理泛化域或跨机器人策略迁移。

当前协议要求两个恢复窗口不重叠。Go2第一推第51步，窗口截止第132步，第二推第172步；repeated检验充分间隔的两次恢复。恢复期限内再次受推是未覆盖的时序条件，直接关联NEW_WORLD_PHASED_PLAN_ZH.md的“连续扰动”要求。

有关四足可恢复性的研究也强调扰动时刻的作用，但研究中的步态不能直接替代本项目的站立定义：[Quadruped Capturability and Push Recovery](https://ieeexplore.ieee.org/document/10077785/)。这里只借鉴审查时序覆盖的理由，不从论文数字导入新阈值。

若需要新协议，优先论证两个平面速度增量事件的到达间隔、序列恢复含义与训练覆盖；仍由Push任务拥有，不新增机器人名特判、足接触角色或第二套harness。先固定目标与全部离散时序类别、预算和停止规则，再测量；不能在测量后调整时序求入带。将某类时序完全排除训练属于更强的OOD研究，需要单独界定其资格/后续研究归属。本文件尚未预声明任何新的时序训练或扫描。
