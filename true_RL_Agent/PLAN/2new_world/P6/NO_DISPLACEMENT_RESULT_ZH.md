# Go2：取消位移限制后的短间隔80%外力复测

新J三个seed（10042/10043/10044）的总体成功数为44、52、46（各64）；重复层为11、9、7（各16）。分母包含尚未等到第二推就已失败的回合。

成功继续要求：全程未触发倾倒/高度失败、所有计划力脉冲完整且验证、最后受力之后81步内连续16步满足恢复状态、303步回合结束仍稳定。没有删掉这些要求来抬高成功率。本次剩余50例全部触发姿态或高度失败：前倾3、后倾2、侧倾13、高度塌落32；没有仅因位移或恢复超时失败的例子。因此本批“未触发跌倒/高度失败”与“完整恢复成功”的数量恰好相同，二者定义仍有区别。

## 2. 原来被位移门截断的回合

按同seed/env配对，原I的27个越界失败中，J有21个成功、4个侧倾、2个高度塌落；其中重复层18个对应13个成功、3个侧倾、2个高度塌落。新J实际越过旧边界的回合也为27，其中21个成功。两条运行/评分路径均取消了空间失败，越过旧边界后仍继续采集真实物理轨迹。

这不是给旧记录重贴标签：所有J回合都重新运行至真实失败或303步。原27个回合中11个在原终止点之前的状态逐位相同；其余受到并行物理及前序重置历史差异影响。相同seed不等于全部轨迹精确延续，不将27个配对结果全称为旧轨迹的确定性续跑。旧121个成功在J均成功；另有一个原侧倾例改为高度塌落，总体仍失败。
