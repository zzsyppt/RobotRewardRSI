# P3：C2 卷间构造审计与修订

2026-09-09。本轮输入为用户对 C2 卷间难度和 sealed 判据的审计。目标是消除构造造成的混杂，保持可信的任务 × 机器人比较；不以 Go2 获得 GO 为交付条件。执行结果将在本页及当前验收页更新。

## 已核实与需要纠正的判断

- 当前 G1/Go2 的三道 C2 均继承同一平面对照的位置，导致 accept 同时取负高度位移，三道题没有分散该变化。这是构造问题。对照由公开标定选择，并非所有未来机器人必定选择 level 5；代码已有较低对照的测试。
- 三卷同时改变高度、表面相位和种子。现有均值随高度排序，支持调查高度混杂，但不能据此断言差异全由高度造成、排除采样波动。应称同一模板的不同实例，不是相同几何题面。
- `evaluation_contract.py:evaluate_unified_stair_sealed_score_gate` 已对 candidate 执行 `sealed >= public - 0.05` 和绝对下限；生产组装和公开投影复算均调用它。reference 明确只记录 sealed 表现。不存在需要在公共层新加判据的缺口；补做现有行为的实际验收。
- G1 的 reference 资格与 Go2 分格判断；资格通过不等于 P4 编排与成本合同已经完成。本轮不启动候选研究。

## 测量前固定的实施规则

1. 保留 `[0.2, 0.8]`、public-accept 资格来源、评分、候选接受公式及 `0.05` sealed 容差。公开 calibration 是选题资料；dev 不是本次选题的 calibration 数据，不将资格改到已经见过且恰好通过的那一卷。
2. 仅从上一轮公开 fine calibration 取原先选中的模板，保留选择及顺序。C2 在 dev/accept/sealed 使用原标定的同一基底、振幅、频率、网格，仅将表面相位相对 calibration 分别移位 2/4/6，并使用各卷种子。不重选基底，不重标定振幅，不取三卷成绩最好的参数。
3. 与 C2 配对的平面控制同步固定，允许这一个实测控制跨卷复用。它只证明基底能力，不计入当前主目标，也不宣称为新几何泛化。其余目标及控制沿用原生成规则；任何非配对控制的跨卷几何重合仍被拒绝。
4. study final 保留既定的新基底几何外推规则和搜索前承诺。它检验更广的未见组合，不能被描述为 C2 仅相位变化的同难度复测。此次资格的 final 探针消耗自己的 study，后续研究不得把它冒充未使用的 final。
5. 新 suite/protocol hash 与旧证据分开。旧三卷已被人工审阅；保留其 NO-GO/PASS 和原始计数，不将复用的非 C2 题面宣称为全新 holdout。新回执只用于检验预先声明的修订，无论通过与否都保留，不根据 accept/sealed/final 再改题或重跑求通过。

## 实施与验收顺序

1. 保存进场源码和旧声明身份；独立复算各卷几何、计数、分差、接受余量，核对用户数值和因果断言。
2. 在 Stair 地形生成与几何隔离边界内修复；测试覆盖两本体、较低及 C1 平面对照、C2 固定基底和相位留出、非对照重复几何拒绝。共享 runner/AgentCore/机器人事实不承接地形语义。
3. 从原公开 calibration 一次性重新冻结两套声明；验证训练/reference/接受门/模板选择未变，旧回执仍可按旧声明复算。
4. 先完成相关回归，再在目标后端各跑一次完整资格（三卷与一个独立 final 探针）。沿用每 cell 每 seed 12 episodes、3/5/7/7 seeds，零训练、零 provider 请求。两种本体资格作业合计 GPU lease 上限 2 小时；基础设施错误单独记录，不把失败进程当科学结果。
5. 执行本地全量及目标环境必要动态检查；核对原始回执、sealed 候选反例、几何查询与真实 mesh、历史 checkpoint、源码部署和进程/lease 收尾。已有其他回归进程不停止、不覆盖其运行源码。

本次不扩大 roughness 来追求带内成功率，亦未解决此前表面形状像崎岖坡的设计限制。工程修复、reference 资格和地形适用范围分别给出结论。

## 固定修订后的测量与同类复核

| C2 当前卷 | Go2 成功 n/N（三题） | G1 成功 n/N（三题） |
|---|---|---|
| public-dev | 33/36、23/36、27/36 | 24/36、28/36、22/36 |
| public-accept | 48/60、48/60、47/60 | 40/60、37/60、33/60 |
| sealed-validation | 76/84、65/84、64/84 | 54/84、50/84、52/84 |

三卷对每个机器人使用同一 C2 基底。两个 accept 的五个目标 stratum 均有带内转折，两个 reference 资格 mask 均经生产 reader 接受；没有放宽上界。Go2 的两题正好为 80%，属于原规则包含的边界，不能据此声称余量很大。全体成功计数、J、family 与 final 单列于 [当前验收](ACCEPTANCE_ZH.md)。

对原审计的第二点，当前源码已有候选 sealed 门，因此没有添加或删除公共层策略。真实组装与公开回执复算两条路径的测试均覆盖 G1/Go2 当前 V3；候选超差被拒、reference telemetry 通过、伪造成功状态被复算拒绝。把 reference 分差称作“已经花掉的候选预算”并不准确：每个候选检查自己的两卷分数。

继续检查了非 C2 构造。C1 的三个模板使用不同轮换位移，三卷平均 riser/tread 基本一致，没有 C2 的整组继承位置错误。但这不保证非线性的策略响应一致：本次 G1 accept−sealed J=0.057534，C1 贡献 0.050519，C2 仅贡献 0.001147。具有相同分数的候选会被现有 0.05 门拒绝。这是实际剩余差异，不能宣称固定 C2 顺带修复了所有卷间难度问题。

G1 的 dev C1 为 35/36、35/36、6/36，sealed tread-OOD 为 70/84、71/84、5/84；两处都没有带内转折。当前 reference 资格规则只在 accept 检查转折，本轮保持它，不因新的结果再移动判定卷或改变门。资格通过不能扩写为各卷均有同等区分力；P3 的完整泛化目标不能仅凭这两个 PASS 宣布完成。

已确认的源头问题已在 Stair 构造边界内解决。没有复制生成器，也没有新增 RobotProfile 阈值、共享 runner 特例或另一套评分器。`stair_geometry_variant` 的 C2 变换仍有 study final 活消费者，不能因正式三卷改为固定基底就误删。需要保留的历史 reader、旧声明和完整 15 rounds checkpoint 继续按原身份验证。

两本体三卷与各自 final 共 12,672 episodes；八个 typed attempt 均 completed，GPU lease 合计 1.115479 小时，低于预声明 2 小时。真实网格/查询的 8 个 cell、59,392 个顶面三角形，以及 6 段原生视频解码/旁车/hash 均通过。当前 [独立复算](results/cohort_alignment_20260909/qualification_analysis.json)保留全部原始计数绑定；final 已被本次探针消费，不能给下一次候选研究复用为未见证据。
