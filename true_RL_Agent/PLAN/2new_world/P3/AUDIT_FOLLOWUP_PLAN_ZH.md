# P3 复审与修订实施计划

2026-09-09。输入为本轮用户审计；以当前源码、公开 reference 标定及目标环境为准。此前 P3 的工程记录保留，新题池和评分须重新验收，不能继承 2026-09-08 的资格 GO。本文保留首轮公开标定与冻结规则；后续 C2 比例修正见 [回归复审](REGRESSION_FOLLOWUP_ZH.md)，基底卷间偏移的最终修订见 [卷间构造审计](COHORT_ALIGNMENT_ZH.md)，活动声明与资格状态以 [当前验收](ACCEPTANCE_ZH.md)为准。

## 判断与顺序

1. **目标归属。** 当前 G1/Go2 的 ID 与 phase control 已饱和，从新研究主目标移除，保留明确的能力守卫和原始报告。主目标由 scalar、C1 frontier、C2 三个任务 family 等权组成；cell 仍为 0.5 success + 0.5 progress。不按候选成绩更换计分 cell，不新增耗时分。这个范围是当前研究的合同，不是宣称所有未来机器人的 ID 都无价值。
2. **标定与样本。** 增加每 cell 的并行 episode 数；先在公开范围粗定位，再用同一 reference 在转折附近细化。每轮范围、样本量、停止条件先冻结。保持容易/困难控制与转折题的角色清楚；不能靠保留大量天花板锚点稀释改进，也不能只保留偶然成功的 cell。
3. **跨本体参数。** 收窄踏深使用相对训练域、按 L 有界的变化，去掉 d0 必须大于 0.25L 的不合理限制。工厂直接消费训练 profile、机器人事实和八种 stratum 定义，不再要求新机器人先抄 72 个旧 suite 几何。训练的米制场景设置仍是训练条件，不在评测修复时悄悄改写。
4. **真实留出。** 用有实际尺度差异的高度/踏深或表面组合生成 dev、accept、sealed 和 study final；按 ID/OOD 归属约束几何，公开标定后冻结，不看 sealed 再选题。保留研究承诺、resume 和显式 replication。修复 private suite 的序列化/实际 cell 不一致。
5. **局部代码收敛。** 强制保留 C2 对应平面控制；删除 C1 level-5 残留特例和裸 15 mm 上界；公式声明单源；成功进度下限读取 semantics；删除无消费者的 completion 派生统计，保留 episode facts；区分 family 局部证据与整体资格，修复 mask 自相矛盾。
6. **入口与维护。** 将标定移到 scripts 的可复用入口，补充新机器人接入步骤；三个正式入口默认使用本次验收后的主线。冻结旧 15 rounds 的 V1/V2 reader、协议、checkpoint 不动。binding 历史副本和已有 mask 承载的 public-result 身份先按实际消费者判断，不为省数 KB 改造公共协议。

## 验收和资源边界

- 每项审计有 `fixed / retired / retained_with_reason / not_reproduced` 结论；数值说法另行复算，不直接照抄。
- 最小必要反例：ID/phase 改善不提高主分但退化受守卫保护；失败/成功 facts 遵循 semantics；C2 非最高档平面控制仍存在；C1 pattern 覆盖；小/大 L 工厂可生成合法几何；private suite 序列化与 cell 一致；新的默认入口解析到新题池。
- G1/Go2 均使用现有完整新后端 reference，增加样本后重新公开标定、冻结、独立 qualification。真实图形/物理、网格查询、配对 seed、原始计数、suite/hash 与训练身份一起核验。不得重训 reference 或运行 LLM 搜索。
- 本次新增 GPU 上限 4 小时；标定最多一次粗定位、一次细化及一次公开失败修正。用实际资源占用记录成本，先核对 GPU/进程；未达资格如实 NO-GO，不能以工程全绿替代。
- 局部反例通过后进行完整本地回归、开启 Isaac 动态用例的目标环境全量、旧证据复算和必要原生录像；三个 generation session 场景不得跳过，专项不能替代全量。发布前后核对字节，完整 15 rounds checkpoint 继续受保护。

实施参数以首轮测量前写入的冻结 suite 和本文件补充为准；测量后修改必须保留原因和前一版结果。最终判定写入本目录验收记录。

## 地形优先与跨本体边界

成功率饱和首先说明当前题池不能区分策略。优先在同一 Stair 任务内调整高度、踏深、相邻踏步变化和表面起伏，使 reference 出现稳定的成功到失败转折；不靠添加耗时、姿态或能耗分来制造可优化空间。若预声明范围仍全部成功或全部失败，本轮资格 NO-GO，再形成有依据的新范围；不能在正式搜索中改题。

同种地形共享生成方法、任务语义与标定规则，每个机器人冻结不同的物理参数，不要求同一米制地形同样难。支撑高度 L 只是初始化搜索尺度；目前 RobotProfile 没有可靠足底碰撞尺寸和最大可达步长，因此不把标称足中心间距当作足长、不把 L 当作运动学可达性。未来确需这些量时，从机器人运行时事实提取并在 Stair 侧消费，不能在共享 runner 或机器人名称分支内藏地形阈值。

本轮复用已训练 checkpoint，不能暗改训练分布来迁就新评测。高度相对训练上界增加、踏深从各自 d0 有界收窄；ID 继续位于原训练支持，困难地形明确属于 OOD。C1 按 pattern 保持覆盖，C2 固定有能力通过的平面基底后只改变表面。宽度、平台、级数与时限保留其任务/训练条件身份，不声称所有米制参数都由 L 推出。

跨本体“适用”指同一方法能定位各自可测转折；独立 cohort 和研究 final 检验同种地形未见实例。两台机器人同样成功率不代表物理能力相等；合成 L 测试只证明生成器范围可用，不能代替新机器人的物理标定。训练支持要随新机器人改变时，应建立新训练协议并重训 reference，不能复用评测后继的训练身份。

## 首轮测量前冻结的具体规则

- 每 cell 每 seed 12 个并行环境，calibration/dev/accept/sealed 分别 3/3/5/7 seeds。因此标定每 cell 36 episodes，accept 60，sealed 84；完整标定 576 envs，正式评测 288 envs。增加 rollout 样本不等于增加独立训练 seed。
- 踏深粗范围为 `d0 - min(0.5L, 0.75d0) × [.05,.2,.4,.6,.8,1]`，其余高度和 frontier 粗档沿用已公开范围。训练的绝对米制场景条件保持不变；本次不声称一个 L 可以推出所有足部/身体几何。
- C2 从粗测成功率 ≥0.9 的 ID 中选最高平均 riser 基底，随后六档 A/min(riser)=[.04,.10,.18,.26,.34,.42]；波长目标仍为 .35L/.70L，每周期 4 网格间隔。实际整数周期和米制值写入 suite。网格容量扩大到 128 周期/513 顶点以覆盖小本体，不改变 G1/Go2 的实际网格。
- 细化为一次：规则地形和 C2 取最接近 50% 的粗档及相邻区间，均分六档；C1 frontier 分 pattern 各细化两档（区间的 .35/.75），未夹住转折时只向已声明粗范围的端点延伸。更换了 C2 基底时先测完整振幅范围，不拿旧基底的成功率作插值依据。
- 正式目标选最接近 50% 的三档，C1 frontier 每个训练 pattern 一档；ID/phase 选择覆盖各 pattern 的最难 ≥90% 控制。C2 的平面对照强制包含，不能被锚点选择挤掉。ID/phase 不计入当前研究主分；不根据候选成绩更换题或分母。
- 三个正式 cohort 对三档循环分配高度 `[-.02,.007,.02]L` 与适用踏深 `[.025,-.025,.009]L` 的变化，避免整体单向变难；ID 维度保持训练支持，外推维度保持训练外。C2 与平面对照共同变换基底，surface phase 按 cohort 留出。
- Study final 的非零高度/适用踏深幅度为 `.025–.045L`，使用研究 nonce 生成；与前三套卷属于预声明的不同几何实例。它不再依赖亚毫米扰动区分身份，实际难度是否仍可比须如实测量，不能仅凭几何 hash 判定。
- 保留原接受合同的 20% headroom reduction 和配对误差规则。去掉常量天花板改善目标解释，并不自动提高通过率：当变化只是仿射重标度时，headroom 阈值也会一起缩放。差距是否更有辨识力必须看转折题上的实际结果。

审计中的二项分布示例经复算：若 9 个独立 episode 的真实 p=.95，落入 [2/9,7/9] 的概率为 7.1211%，不是 8.6%；相同口径 36 个样本降为约 0.03346%。这只说明增加样本的价值，不把同 checkpoint 的 rollout 当成独立训练复现。
