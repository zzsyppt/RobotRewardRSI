# 独立诊断模块的边界与粒度

2026-09-30。依据用户关于独立描述、压缩主上下文及由主代理结合画面单独验收的授权。本文明确当前主线，不新增阶段、不恢复作者 A/T 实验。开发验收记录见 [本轮复核](./results/diagnostic_module_review_r1/REVIEW_ZH.md)。

## 1. 模块如何工作

采用一条短链：**同轨证据 → 任务数值过程 → 有界形态观察 → 核对与投影 → 作者短报告**。

完整时序、原始双视角图、定义和模型原答保存在外部档案。任务层负责成功/失败含义、过程谓词、恢复驻留、地形/身体坐标和选窗；公用层只负责身份、时间引用、媒体预算、输出合同和投递。主作者不接收观察者的长推理、全帧录像或完整轨迹数组。

“独立模块”首先是清楚的输入输出和独立上下文，不等于新建常驻服务或多代理平台。现有 observer、任务派生和报告投影继续复用。最小角色是一个描述者和一个核对者；计数、时间关系、数值命题由程序核对，自由形态文字由实际看图的模型核对。模型核对不能把自己的判断升级为物理测量，也不能批准训练或改变任务规则。开发时主代理可以承担核对角色；正式 N.5 的独立双评资格仍单独管理。

目前已具备任务数值派生、观察者合同和预算、原答留档、任务投影、作者投递。v1.4.11已加入任务姿态短事实及独立语义review附件：未经评阅的自由文字不再自动进入S3；supported需覆盖原句text与uncertainty的所有命题。程序检查票、引用和原件绑定，**实际判断仍由看图评者承担，尚未实现自动核对者调度**。机械通过及数值consistent仍不能认证整句，核对者的判断本身还需独立验收。详见[研究与实现决定](./SEMANTIC_GROUNDING_REVISION_ZH.md)。

v1.4.12进一步把部位身份与几何交给已有仿真信息：具名link坐标通过同一RGB实际相机标定定位到图像；任务/资产层解释少量锚点和夹角，公用层只处理坐标。观察者每图最多六个位置、每回合最多五条测量事实；完整世界坐标、相机矩阵及其hash只留档。投影在画内仍可能被遮挡，palm link原点不是手掌中心，左右几何也不自动等于整体下蹲。实现及真实验收状态见[部位定位说明](./BODY_GROUNDING_NEXT_ZH.md)。

## 2. 粒度由证据决定

默认描述到“身体部位 + 可辨状态/变化 + 时间范围 + 环境关系”，不规定每个回合必须有几个阶段。

| 证据 | 合适表述 | 不应推到 |
|---|---|---|
| 几个稀疏时刻躯干姿态相近 | 在这些显示时刻均保持立姿，局部肢体配置有变化 | 整段一直稳定，或强行分成反复蹲起 |
| 数值表明前进减少、倾斜区间重叠 | 两个过程在相应区间重叠，并列出终局 | 前进减少导致倾斜，或把重叠改为先后 |
| 双视角显示侧转，向上轴转为负 | 在显示点发生明显姿态翻转；精确越界步来自数值 | 单凭终止标签推断碰撞部位、力或原因 |
| 任务恢复驻留曾达成，末步速度又超界 | 曾恢复，后又失稳，末步未满足速度条件 | 把外观“还站着”称为任务恢复成功 |

两个机位应补足遮挡、方向和相对位置，合并同一事实，避免各写一遍相同故事。左右腿或多个关节变化不一致时，不概括成全身同向屈伸。无需为了高层语言省掉决定性的中间状态；也不为让故事完整而填补未显示的时间。

## 3. 新语义与多模态

没有匹配词条时，先用已有测量和可见形态组合描述，明确未分类部分；未匹配不代表行为不存在，更不意味着异常或新物理原因。未知出口保留证据定位、哪些部位/时段不可辨、需要什么新观测。候选词条可留档，不能由模型一次描述自动晋升为任务规则。

数值和视觉只在**同一次运行、同一回合、同一时刻/窗口**内互证。当前开发报告的数值代表回合与视觉回合并不相同，分别可用，但不能把它们拼成同一个机器人经历。视觉补形态，数值提供严格时间、驻留、位移和边界判断；模型提出的原因及奖励修改仍是待检验假设。

仿真已记录的关节状态可用于复核具体屈伸主张，不需要视觉重复猜角度。是否向观察者提供这些量，应由任务/机器人适配器按当前问题给少量具名量及定义；不能把全部关节时序灌进共享提示。此次额外复核读到的 Push 膝关节量并未提供给旧 r8 观察者，不能反过来算它当时已经利用了该证据。

## 4. 上下文和记忆

主作者默认只收到现有有界报告：结果、关键过程、成功反例、形态补充、缺口、可比较父差分及可表达的修改范围。Stair 8 KiB、Push 12 KiB 是序列化字节上限，不冒充 token 数。关键主张保留回合、窗口、分母和可解析出处；长原答和图像按需从档案取回。

观察者与核对者各自拥有有限工作集，跨调用累计计媒体预算，不能靠派多个代理绕过。派生缓存按证据、词条/提示/投影版本识别；旧摘要不能脱离版本成为永久事实。主作者的长期记忆只保留经确认的行为结果、失败假设及其证据引用，未知和模型假设不自动写成任务知识。

正式评阅为了核查完整过程需要较大的独立上下文，这是验收材料容量问题，不应把同样的数组送给主作者。当前数值评阅压力检查 35/36 单位进入目标，最长 Stair 报告仍超目标；此项未解决，不宣称 N.5 已就绪。先完成诊断内容本身的开发验收，不继续为这一项搭建通用分片平台。

[容量复核](./N5_CONTEXT_RECHECK_ZH.md)已明确180k只是预检目标；放行最终取决于实际模型配置、材料量、系统/工具开销、输出预留及计数误差。当前仍缺足够证据，不能仅把目标改大就宣布通过。

## 5. 本次验收与紧接着的工作

主代理直接看原图，核实对应状态、原答和真实送达短报告，逐项记录准确性、粒度、遗漏及范围越界。此为非盲开发验收，可发现和修复问题；不覆盖此前原评分，不冒充独立 N.5，也不证明训练收益。

旧 r8 的 Push 反复蹲起叙述不予接受；Stair 的显示点躯干方向概括得到支持，但重复描述不增信息。通用描述要求已修订，固定三个旧开发回合的一次性 r9 检查已完成；原答仍有格式失败及姿态粒度错误，见[后续验收](./results/diagnostic_module_review_r1/R9_REVIEW_ZH.md)，不重试刷通过。

**源头分工已开始落地：**对定义明确、现有同轨状态已记录的root姿态生成少量可核短事实，保留精确S0；不能让模型把root高度、根部姿态、左右膝坐标和全身“蹲深度”当同一个量。原始坐标到“更屈/更伸”的语义仍需资产/关节定义，本轮未添加膝语义。模型保留未被测量覆盖的形态、环境关系与不确定部分；未知形态不强塞进已有阶段词。实际看图的核对者给出独立于机械结果的逐句意见，由投递边界消费；这一步工程就绪不等于模型描述质量已经通过。

开发检查暴露的错误是进入正式验收前要处理的能力缺口，不能用主代理写出的正确目标描述替换自动输出。随后才封存最终源码和材料、解决剩余正式材料容量、执行 N.5。P4 和训练不提前启动。
