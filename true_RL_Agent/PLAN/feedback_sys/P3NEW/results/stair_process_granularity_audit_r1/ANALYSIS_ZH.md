## 3. 姿态与窗口关系不能翻译过头

独立复算的负向 pitch 严格越过 −0.65 rad 区间为 **101–104、314–322、332–338、423–436**。没有正向 pitch >0.65 或 |roll|>0.65 区间。前三段分别 4、9、7 步，未达到原 10 步确认门；末段 14 步，在 432 步确认。原 root event 索引分别为 127、394、426、511，原事件完整保留了未确认状态。

这给过程关系提供了真实信息：第一段主要回撤时有短负向 pitch 越界；第二段主要回撤附近有两次分开的短负向 pitch 越界。但是：

- 第二段附近的第一段 pitch 越界从 **314** 开始，比进度峰值 315 早一步。局部段内统计只能称交集 315–322，不能把原事件开始改成 315；原事件引用仍应保留 314–322。用“附近/相交”比“回撤之后发生”准确。
- 第七段只与末次 pitch 越界的 434–436 部分相交；原完整越界仍是 423–436。新增进度片段不能替代或删掉这个已确认姿态事件。
- signed pitch 是既定四元数约定下的 Euler 分量。此材料不能单凭符号升级成“低头、仰头、倒向台阶”等需要机器人轴向/视觉依据的描述。
- 低进度窗口的**窗口结束步**为 105–131 和 336–347。定义是跨 0.5 s 的 26 样本（25 间隔）窗口内 `max(x)-x_start <0.02 m`，不是当时速度为零。第一段已在 116 后回升，但窗口谓词仍持续至 131；不能写“105–131 停住不动”。

原事件证据：`full_derivation /complete_episode_derivation/events` 的 `columns/rows`，以及本次 `evidence.json /full_root_events`。定义在 `raw_numeric /definitions/window_definition` 和 `/definitions/protocol/episode_outcomes/signals/base_orientation_instability`。

## 5. 代码层面的原因与最小修正方向

本节指**审计开始时版本**：`behavior.py` SHA256 `60c4358f1f2a16410aa69614b65b5235125b63c2a0c90da39272237b22c53aa3`，`process_report.py` SHA256 `c6180c36d73c63b0bd086f16733d4da22645915113c9e8153365cb4615f6a969`。后续实现正在另行进行，本文不是对新代码的验收。

- `behavior._Episode.observe` 原 109–129 行只保留 whole-episode signed 极值与一组三元 `max_x_retreat`。所以缺失并非模型没有把已有返回字段串起来，而是完整派生本身丢掉返回与其它进度段。
- `process_report._timeline` 原 318–340 行每类挑一个已确认区间（优先 terminal，否则最长）。这不能表达本例两段主要回撤及未确认但实际发生的 signed pitch 变化。
- `_sentences` 原 354–409 行给失败主代表额外全局 root S0，但成功反例主要仍走 timeline。不能因成功便丢掉“过程出现回撤却最终成功”的对照价值；也不能在只审一回合完整切片时假定它已被选作主代表。

建议只在 Stair 任务层新增描述性 `progress_excursions`/同义结构：完整保存峰值、谷值、首次重返或 terminal 截尾、幅度、局部 signed roll/pitch、已有事件引用。它不改奖励、终止、原事件确认门或 foot reference 的定义，不引入“尝试、碰撞原因、恢复平衡”等新任务推断。

完整派生保留所有段，不加幅度阈值。短报告选最大两段；如果终点仍有未重返段则优先保留，并明确展示/总数。只按幅度选两段并不意味着其它既有重要事件可以消失：例如本例 423–436 的已确认 tilt 仍应由原 timeline 保留。定义 tie、first return 与 terminal 同步重返的处理即可，不需要新的分段平台。

一个合适的示意粒度是：“这个成功回合有两段主要 root x 回撤：84→116 约 0.126 m，141 重返原 x；315→331 约 0.088 m，355 重返原 x。两段附近有短暂负向 pitch 越界，未满足持续确认门；后段 423–436 另有已确认 pitch 越界，终点 525 记录成功。进度段展示 2/7。”这是本次人工分析示意，**不是已生成并投递的自动报告，也不是视觉描述**。

最终应检验的是：源头是否保留真实片段、短报告是否准确表达所选片段和遗漏、成功反例是否保持同一语义、任务内概念是否仍留在任务层。无需为了补这个缺口继续扩大事实清单、改原分母，或重写传感器/终止系统。
