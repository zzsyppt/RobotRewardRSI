## 信息量与下一步边界

数值主线仍负责失败过程：恢复窗口曾满足、随后又失稳、末步不满足条件等。视觉不必重新编一条完整故事；本轮Push左肘形态可以成立，但不是失败机制，不能替代该主线。Stair倒置是有用的粗形态，其余相机投影状态的诊断信息较少。

下一缺口是**部位身份与局部几何**。给出一串body名称不等于图像中的部位已定位；给root角度不等于已给膝角。应先核实已有快照/仿真状态能否提供少量具名部位位置、相机投影及经过资产定义的几何关系，再决定局部观察需要的证据。不能从关节q符号、body原点或人体阈值猜机器人屈伸，也不继续靠叠加提示和重复调用碰运气。未知形态保持较粗且可定位的组合描述。

自动核对者尚未接入运行调度；当前附件由主代理实际看图产生。后续运行核对者是被验系统的一部分，不能兼任N.5真值。N.5最长材料容量仍待处理，正式新采集/双评、3-live、P4均未启动；P3-NEW保持IN_PROGRESS。
