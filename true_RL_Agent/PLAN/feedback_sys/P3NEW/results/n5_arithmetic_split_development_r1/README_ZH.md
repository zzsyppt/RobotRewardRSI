## 尚未证明的范围

- Stair 的表面高度、瞬时力范数和历史范数最大值来自已供直接操作数；原始几何计算、力向量/历史槽未在此入口独立重算。
- Push 以已供 pose 和 planar_motion 为操作数；没有重新从四元数/完整速度重建所有 pose 列，也没有动作数组来复算动作指标。
- 未恢复事件的 latency 数值代码、未成功窗口外的原始 dwell 寄存值缺少充分的材料定义；不把 horizon 代码当作实际恢复耗时，也不通过抄生产实现强制本入口“全绿”。符合资格的窗口内驻留、最大值、闩锁及实际时段已经复算。
- 两任务的终局标签只核对原始记录的复制，不另造物理成功/终止分类。来源身份、训练/评估绑定、词条物理解释与群体选择合同分别由其所属的核验层处理。

这些范围需在正式责任清单中分别说明：哪些是经过既有采集合同提供的测量输入，哪些仍需要同源原件复算，哪些是身份检查或语义评阅。不能把“本函数没重算原始测量”泛化成“测量必然错”，也不能把“派生一致”泛化成物理真值。

## 材料进入评阅者的边界

现有 runner 只增加 report 阶段的 `arithmetic_audit` 角色，没有增加调度平台。利用真实旧材料验证：report 请求完整保留程序核验记录；facts 请求明确拒绝该角色，防止必要事实阶段受到自动派生核验结果提示。[边界检查回执](./material_role_check.json)只有CPU构建，没有实际发送。
