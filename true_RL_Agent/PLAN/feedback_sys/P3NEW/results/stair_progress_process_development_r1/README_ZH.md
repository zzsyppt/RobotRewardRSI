# Stair：把进度变化及其结果保存在同一过程片段

2026-09-30。**开发工程与独立算术检查完成；不是 N5、新确认语义评分或训练收益。** 本次修改仅在 Stair 任务层；生产代码不引用 PLAN。

## 为什么修改

独立核对旧成功回合 `r1.e60` 发现：84→116 步回退约 0.126 m，141 步重返原 x；315→331 步回退约 0.088 m，355 步重返。原完整派生只保存最大回退三元组，短报告又每类只展开一个已确认区间。因此“怎么走过来的”在源头就丢了，不能靠更强的观察模型或更长形容词补回来。详见[原量审计](../stair_process_granularity_audit_r1/ANALYSIS_ZH.md)。

## 实现与表达边界

`behavior.py` 新增任务内 `progress_process`：从已有逐步 root x、signed roll/pitch、up_z 构造所有正回撤，保存峰值、谷值、首次重返峰值或终点截尾、局部姿态极值及其步号、相交原 tilt/low_progress 事件索引。未改变原事件、确认门、奖励、成功或终止。相同峰值取下降前最近一次，相同谷值取第一次；没有新的幅度阈值。极小波动也保留，因此总数不能翻译成尝试次数。

`process_report.py` 的派生版本升为 `stair.process_report.v2`。完整派生保留全部片段；短报告按时间显示最大两段，并优先保留截至终点仍未重返的一段，公开显示数/总数。失败主例和相容成功反例均描述变化及其后续结果；原已确认姿态时间线继续保留。重返 x 只代表重返 x，不等于恢复平衡，也不证明区间单调。Euler 分量不直接改写成低头/仰头或碰撞原因。

同一受保护分组的对照计数、rule-negative 和 comparison-missing 现在写在同一行，全部数值与分母保留；删掉重复的组名和重复定义，未扩大 8 KiB。旧 public v1 派生记录仍可原样读取，与新版比较明确返回版本不可比；旧 full 工件不由新模板静默重写。

- [独立检查](./independent_check.json)：另用 NumPy prefix-max/连通段方法核对 12 回合的 49 段、4 段终点未返回；完整集合、峰谷/返回步、null、局部 signed 极值、原事件索引一致，五个边界例通过。原 global-max 三元组保持原语义。
- [独立验收入口扩展](./verifier_extension_check.json)：集成到既有 `verify_stair_confirmation_arithmetic.py`，不调用生产 reducer 造真值。旧 12 包返回字节不变；新字段全对象通过，删段、错误返回/null、符号和事件索引四类变异均被发现。
- [容量检查](./projection_check.json)：实际新数值报告 6,515 / 8,192 B。加入 200 字正文、120 字不确定性、12 个原图引用及合成 parent 差分，三字节字符为 7,857 B，四字节字符为 8,177 B；完整视觉句仍在，过程、成功反例和缺口不变。媒体、评阅与 parent 均明确是容量 fixture，不是画面支持证据。

- [实际请求序列化](./delivery_check.json)：复用生产 context builder、初稿/源码续答/静态修复/推理耗尽修复及 HTTP serializer，8份离线请求、108项逐句送达检查通过；新过程、反例、残差与actionability原样存在。网络边界使用fake opener，没有真实模型发送，不能记为作者已阅读。

原量重算脚本是 `rebuild_full.py`；后续只改呈现时，`verify_projection.py` 核对已重算 measured 与行为源码 hash 后复用，避免重复 CPU 全档案工作。旧 P3/P3R/评阅原答和冻结源未覆盖。测试与最终源码摘要另见 `final_checks.json`。

## 全局判断与剩余边界

最小有用的高层单位是“起点—变化—结果或截尾—必要姿态背景—出处”，不是原始字段清单，也不是先发明一个动作名。未知形态仍可用这些可测关系与已核可见部位组合描述；不能把定量回撤、身体形态和机制猜想合成无出处的结论。

[MotionScript](https://arxiv.org/html/2312.12634v5)的原子时序关系组合给了设计启发；该论文的人体描述/生成结果不证明本项目机器人诊断合格。本次是否有用也不重新启动 A/T 实验。下一步仍是完整材料覆盖、独立语义确认与实际请求送达，不能把上述 CPU 一致性算作模型语义票。新 N5 尚未启动，旧静态源快照不包含本次变化，不能作为最终运行源码。
