# 从姿态猜测转向有依据的过程描述

2026-09-30。P3-NEW 开发修订；研究、实现与实际模型表现分别记账，不改变历史结果或正式验收阈值。

## 1. 全局诊断

r7–r9 已经修过机位、前向轴、步号引用、措辞与字符合同，仍出现“站姿更蹲/变浅”的错误。瓶颈不能继续归结为提示写得不够细：

1. 模型同时承担读取图像、解读数值、决定描述粒度、组合时间过程，生成的一句往往混入多种命题。
2. 数值核对由模型自己挑一个布尔谓词。这个谓词正确，无法担保旁边的姿态文字正确。
3. 现有投递选择以机械合法为准，缺少自由文字的语义准入。后续再标“predicate only”虽诚实，却未阻止错误句进入作者。
4. S0 在每个时刻重复单位/来源/坐标定义，读起来像参数表。重要方向含义没有转成易读、可复算的小事实。

本次改变职责分工：**任务与机器人定义测量 → 程序生成短事实 → 视觉只补可辨形态 → 对原句全部命题核对 → 有界投递**。数值过程仍是骨架，视觉有独立上下文，作者不接收完整数组、全帧图像或观察者思考过程。

## 3. 粒度与未知过程

粒度分为**部位状态、采样端点差、连续区间过程、组合行为**。这些是证据要求，不是必须依次填满的四级标签。

- 一张图只支持该时刻可见状态；两个时刻支持端点差；“持续、逐渐、反复”需要覆盖相应区间的证据。
- 躯干方向、根部高度、左右膝坐标和整体蹲姿分别管理。只有组成事实全部成立、参照系正确且时间相容，才使用更高层词。
- 未知行为先用已知事实的新组合描述，例如“前部抬高，后段侧转，末帧倒置”。不必先有动作名称；接触原因、承重方式等未证实部分明确留下。
- 不用人工设定的“几度以内都一样”掩盖微小变化。原始值保留；显示值近似舍入，不代表真实值严格相等。是否值得描述交给任务相关性和可辨性评阅。
- “不足以判断两膝变化”不等于整段拒答；数值扰动、稳定区间、再次失稳和最终状态仍能构成有内容的过程报告。

## 4. 本轮最小实现

### 已测姿态事实由任务生成

Stair从原有同轨root轴分量生成各显示步的前向仰角、向上轴相对世界+Z夹角及地形原点相对高度。前向定义缺失时不生成前向事实。Push加入原档案已有的有符号root Euler roll/pitch，与原高度共同形成三个维度的采样事实。

每任务最多三条短事实，每条只描述一个测量维度，并引用原S0的name/step。角度显示近似到0.1度，高度到0.001m，精确数值仍在S0中。没有新增姿态类别阈值，没有新增采集，没有把root旋转当作独立torso link或膝角。

G1快照确实有具名膝关节坐标，资产也有关节轴和固定旋转；但当前配置没有已验收的解剖直膝零位/屈曲定义，Push全cohort NPZ也没有这些关节字段。本次不把局部快照扩称全量已采，不从q增减直接生成“更弯/更蹲”。

共享输入只做合同校验；S0的定义只序列化一次，各采样点保留name/step/value，可逐字段无损复建。短事实新增少量可读上下文，同时去掉重复定义，未增加作者8/12KiB报告预算。

### 自由文字须经过明确核对

新增一个薄的review附件，绑定完整原答、观察、身份、图像引用及数值核对结果。每条原观察都有 supported / contradicted / insufficient 之一，以及评者身份、评阅类型和理由；没有评阅则为unreviewed。复合句及uncertainty中的事实全部支持，整条才可supported。程序校验附件完整和绑定，不冒充自动理解自然语言。

只有机械/任务绑定可用且supported的原句可以进入视觉S3；其余计入S5，全部原答保留。已有数值predicate即使consistent也不能代替语义核对；发生conflict仍显式保留。核对不改写原句，降低粒度须形成下一版本的新描述，不能悄悄修补历史输出。

开发阶段由当前主代理实际看图核对，可接入模型或人工评阅产物；本轮没有新建自动评者调度服务。正式N.5仍按现行独立双评协议，过滤前分母不变。

### 组合报告与上下文

任务的完整数值过程、成功反例、残差和父差分保持；视觉只补充必要形态。模块长证据在外部档案，作者只收到短过程和缺口、出处。核对理由和模型思考不挤入主作者上下文。当前默认只投递一条核对后的视觉观察；这属于容量选择，不能把其余原句从验收分母去掉。

## 5. 验收与下一步

先检查源头算术、坐标/缺测、实际输入字节和review投递链，再用固定两例旧媒体进行一次新表示开发检查。模型调用前单独登记源码、请求和预算；所有原句由主代理结合相同原图复核。零观察或全部过滤只能证明没有投递错误，不能证明过程覆盖或观察能力达标。

开发检查必须回答：正确躯干方向是否利用、细微腿姿是否仍被强编为动作、自由文字与测量是否分清、必需过程是否保留、缺口是否诚实送达。若仍失败，就记录具体能力缺口，不能重试到满意。

P3-NEW正式门槛及数据隔离保持。后续还需处理N.5最长材料容量、重新冻结最终源并完成未用资料确认；本轮代码或旧例结果均不提前宣布整阶段通过。
