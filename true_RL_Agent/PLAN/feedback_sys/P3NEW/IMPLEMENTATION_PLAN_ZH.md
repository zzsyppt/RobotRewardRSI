## 最终交付与实施顺序

1. **N.1 两任务语义报告。** 保留旧完整派生与旧投影语义；Stair 新完整 v3 / public v4，Push 新完整 v3 / public v3。任务模块以现有完整派生生成词条卡、七节自然句、分组事实和合法差分。公用模块只校验 S0–S5 槽位、七节结构和容量；不判断机器人身体或物理阈值。完整句子槽位及引用进入派生工件，默认报告只带可读句子与稳定 id，经工件回查；不再向作者发送 columns/rows 编码表。
2. **N.2 未知与覆盖。** 两任务各自定义残差、签名、相容域和代表选择，输出三态、全域分母及确定性窗口。候选名称只登记，不晋升正式规则。独立复算从 L0 数组出发，禁止调用生产残差函数冒充独立验证。
3. **N.3 开发级观察者。** 复用现有图像编码与 HTTP 传输、媒体包、白名单序列化、回执和预算。任务生成有引用的可读姿态事实，视觉补可辨形态与环境关系；程序核验原件绑定，评者核验每条文字及uncertainty的全部命题。未评阅、矛盾与缺证据不进入事实性S3，但原答、分母与缺口保留。数值谓词映射仅核该谓词。API开发/确认记录实际模型与fingerprint；桌面载体记录可观察配置/材料/读图轨迹，缺失服务端遥测明确为unavailable，视觉观察不得改写 L1/L2。核对者与正式验收评者职责分开，系统核对意见本身也是待验收产物。
4. **N.4 投递。** 从完整派生、短报告到四种实际序列化请求逐层核对。使用旧四开发案例做最多八个作者读法烟测，结果只改进模板，不评建设价值。

正式源码进入 src/scripts/tests；PLAN 只留卡片、记录与证据索引。既有词条、修复帧保真与 CPU/GPU 边界作为起点，不改 success、termination、reward ABI、acceptance 或训练权限。不开发 P4/P5/P6 完整平台，不启动训练或 3-live。

## 本次先定清的口径

- **采样分两层。** N.2 数值窗口目录：每层×成功/失败各至少一回合，并完整选取 `min(k+u,4)` 个残差/缺对照回合；检查相应 L0 数值，计算该层覆盖。N.3通用上限仍为四回合/24图/96子帧；本轮在事前录制的六回合中按原始成功/失败各取固定哈希最小者，共两回合，每回合最多六时刻双视角。首/中/末保证基本覆盖，另外三点取任务事件前/中/后；不按自动报告阳性或模型回答挑例。没有媒体、未发出或被裁掉的窗口明确记未观察。两层都记覆盖，前者不冒充画面已被看过。若某层没有该结果，则记不存在而非补造。主计划对应冲突条款在实现前澄清。
- **残差先判可比性。** 成功对照不足三例、字段或有效窗口不足时先记不可判；否则再判断匹配签名在成功中的比例是否至少 0.5。残差表示现有词表难以区分成功/失败，不表示已证明根因未知或已解释根因。
- **Stair 签名。** 严格终止前已确认的 tilt、low_progress、同体无载低运动、up_z<0；每项首次确认距终局按 ≤0.5 s、≤2 s、>2 s 分箱。分组为原失败原因×cell×run，成功取同 cell/run。代表按四项出现组合众数，再组合内时长中位、编号裁决；声明平票与非多数。
- **Push 签名。** 五条件违反集合及首次违反距实际恢复锚点的同三档时间分箱；比较域含强度、实际执行事件数和窗口 ordinal/定义。每个失败回合：任一有效窗口阳性则阳性；无阳性且有缺对照/无实际窗口则不可判；其余阴性。未执行事件不补假窗口，不拿两次实际事件的成功替一次事件的跌倒补对照。
- **数值选窗。** seed=`p3new-20260929`，每回合三个等距锚点，各向前后扩展 25 控制步，裁到有效区间后合并；残差补充上限四回合。哈希排序、去重、联合覆盖和未选列表均保存。
- **描述性词条从严。** 只进入个体过程与分母描述，不作为 S2 的区分性谓词。成功侧高出现率必须体现在词条卡和反例中，不能用频繁出现冒充有诊断区分力。
- **两个分母不能合并。** N.4 必送核心零丢失；N.5 由原始资料独立标注的完整必要事实计算覆盖≥90%，不得用选择器确定后者分母。

## 验收矩阵与停止边界

| 对象 | 必须保留的证据 |
|---|---|
| 词条、自然句 | 每词条定义/单位/版本/降级/区分统计/困难反例；全部句子及七节lint；全量分母独立复算 |
| 代表与反例 | 众数与平票复算、每条区间及终止前边界、真实匹配域 |
| 残差与覆盖 | L0独立脚本逐域相等，三态完整，数值选窗与媒体送达分别记账，0自动晋升 |
| 容量及历史 | 实际8/12KiB及整请求字节；反例/残差必留；旧投影字节幂等，不改任务终局与接受逻辑 |
| 观察者 | 白名单实际字节、图像/子帧/像素/费用、fingerprint、过滤前全部观察句支持≥90%、越权0；冲突和仅视觉比例 |
| 投递 | 档案/完整派生/报告/末请求四层账；四类请求必需核心0丢失；烟测误读与引用记录 |
| 独立语义 | 两任务各12新回合、一次性双评；校准；支持≥95%、召回/定位≥90%；系统错误/评阅分歧分别记；修正则整包转开发另冻新集 |

不以单测、字段相等、作者完成或开发画面替代正式语义验收。系统性错误、预算不足或必要外部证据未具备如实记未完成/INCONCLUSIVE；不缩验收范围宣布整体通过。
