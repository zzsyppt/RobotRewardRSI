## 原始采集与确定性选择

- 生产源使用 r4 的400文件快照；服务器两条实际静态预检及独立 binding 重建已完成。checkpoint、训练回执、cohort 和 seed 保持已核身份；新诊断运行不生成新训练资格。
- Stair：`public_dev_diagnostic_v1`，288 env×3 seed；预选媒体 env 2、63。Push：base seed 1500000000，64 env×3 seed；预选媒体 env 3、59。按每任务原卡哈希/域排序选择，采集后不换 env。
- 每个预选 env 的首回合逐控制步双视角1920×1080，保留1..真实T及末帧。每任务6个原始媒体回合；图像不裁切、增强或事后重放冒充同步。
- 24数值回合选择复用封存的 `P3R/confirmation_raw_material.py::select/rank`：六个既定scope分别取原始失败中最多终止类别的哈希最小例，再按同cell同run、同cell、跨cell顺序取未用成功反例；无失败按既有全组回退，无成功或不足12个不同回合则INCONCLUSIVE。旧scope重复的Push单位仍按顺序去重，不把同报告六次视为六独立环境。
- 每任务媒体从六个完整回合按原始成功/失败分组，各取 `SHA256(p3new-n5-observer-episode-v1|task|run|env)` 最小者；缺类记INCONCLUSIVE，不补选重跑。每回合首/中/末＋任务事件前/中/后，至多6时刻×2视角；每任务报告共≤24图/96子帧。媒体与数值窗口独立计覆盖。
- 运行加载/准入、实际数值与图像同步、全身/地形可见性在新资料生成后检查；不能用旧图合格代替本次画质。新资料不可辨则该媒体profile保留INCONCLUSIVE，不从密采目录另挑好图改变冻结选择。

## 事实、材料与判断

单源规则为冻结的 [事实评阅协议](./N5_FACT_REVIEW_PROTOCOL_ZH.md)。单包评委只收到其中8组已实现的条款，整轮预算和放行职责由root承担。共享定义保留在完整包内，不新增定义另包或跨请求汇总。

固定24 episode、12 focus、4媒体单位。两家全部40份facts分别封存，才揭示任一报告。五束问题直接采用材料生成器中的Q1–Q5；完整轨迹保留诊断相关量1..T，related_v1的列式表示逐值回转核验；scope全池操作数与被引用实例/反例保留。不能按报告阳性缩小必要事实分母。

独立任务合同包含身体/坐标/时钟、原始终局、作者权限和完整奖励输入ABI，并绑定本次实际 manifest；不把当前源码hash当历史执行证明。Stair数值核验覆盖事件完整集合、身份/确认/null/时序、进度回撤重返、姿态/运动/禁触历史和既有操作数链；Push覆盖条件、全部扰动/恢复/驻留与再次失稳、同一步响应和运动关系。精确覆盖与未核字段由封存的两个独立核验脚本输出；原始测量输入、任务终局复制和语义判断与派生一致性分开。未核不混成PASS。

形式化对象100%独立一致；语义支持≥95%，必要过程召回与定位≥90%，视觉全部原句支持≥90%，越权0，身份/来源/权限硬错0。Stair/Push分开；完整派生、短报告、最终请求分开。校准采用已封存r2的18/20原始一致率，正式下限90%；两项分歧保持。判分与分歧处理不靠开发者改票，系统错误与评委分歧分别报。

本轮最终请求由当前生产入口序列化并捕获，标 `offline_serialized_not_sent`；可以核实际内容，不登记为新真实作者接收。实际HTTP交付依据仅已完成的N.4八次调用；最后两槽与后续Push措辞差异明确保留。**不增加作者调用，不训练，不做A/T。**
