# N.3 原生媒体画质检查（开发记录）

本记录只核对已有媒体与呈现代码；未运行 Isaac、GPU 或视觉 API。原始来源和三张逐帧解码 PNG 的 SHA、step→frame 映射见 [`results/media_quality_check/manifest.json`](results/media_quality_check/manifest.json)。其中第 160 步 PNG 为原视频 1280×720 RGB 解码，未做调色或缩放：颜色正常，但机器狗在全画面约百像素宽，细节难辨。

旧 [`../P3/review_video_20260924/grid.py`](../P3/review_video_20260924/grid.py) 对选定帧先可选裁剪，再一律 `resize((640, 360))`、`ImageOps.equalize`，随后烧录 step。均衡改变了原色与对比度；若裁剪比例不是 16:9，固定尺寸还会改变物体纵横比。这些拼图不能作为原生画质的判断样本。历史拼图、开发包和 API 回执保持原样，不追溯改写。旧开发卡的 `fixed_camera.v1` 描述也不准确：`native_video.py` 现有 viewer 使用 `origin_type=asset_root`、`asset_name=robot`，相机随机器根部移动；新增录制 metadata 明示 `asset_root_tracking.v1`。

后续原生录像只改呈现：通过两任务 replay CLI 的 `--video-dir`、`--video-camera-eye X Y Z`、`--video-camera-lookat X Y Z`、`--video-resolution WIDTH HEIGHT` 传给 eval。eye/lookat 均为相对于 `robot` asset root 的偏移；省略新选项仍用旧默认 eye=(4.5,-4.5,3.0)、lookat=(0.8,0,0)、1280×720。近景候选参数由任务实验卡明确选择，以下仅为尚未实录验收的起点，不写入共享模块：

| 任务 | 待试 eye 偏移 | 待试 lookat 偏移 | 分辨率 | 状态 |
| --- | --- | --- | --- | --- |
| Stair / Go2 | (2.5,-2.5,1.4) | (0.4,0,-0.15) | 1280×720 | 未实录；需确认完整身体、足部和台阶同时入镜 |
| Push / G1 | 待开发录像校准 | 根部附近、略向下 | 1280×720 | 未实录；不能把世界地面高度直接当 root-relative lookat |

Isaac Lab `ViewportCameraController.update_view_location` 实际计算 `cam_eye = root_pos + eye`、`cam_target = root_pos + lookat`，且 `asset_root` 每次渲染更新 root origin。上表高度均相对机器人根部；Go2 候选将目标放在根部下方 0.15 m、略朝前，并非世界坐标的地面高度。Push 尚未校准，不先冻结数值。

提取审核图时仅按已记录的控制步解码 RGB 原帧；保持原始纵横比，若要统一画布则等比缩放并留边。禁用直方图均衡、自动对比度、gamma/饱和度增强和非等比拉伸。保留原 MP4、原帧 hash、相机 metadata、控制步映射和所有提取参数；观察结论只覆盖实际展示的帧。

## 进入正式观察前的画面检查

用户进一步明确要求看清全貌，避免输入质量造成实验偏差。以下检查先在旧开发轨迹完成，相机与布局通过后冻结，同任务新确认材料使用同一配置；不能看观察者答案后换成更容易得到正确描述的机位或帧。

1. **完整性与参照。** 核对首、中、末以及开发录像中已知的大幅倾倒区间：完整身体不被画面边缘或ROI裁掉，地面/临近台阶保留，能判断身体与环境的相对姿态。相机以身体根部跟随时，不能从画面中心基本不变推断世界位移小。
2. **可辨性。** 在最终发送图的实际尺寸上检查躯干朝向、可见肢体弯曲和地面轮廓，不以原视频分辨率或放大后的画布尺寸代替。自然遮挡、同色难辨及画面外细节须保留为不可判断范围；看不清的脚不能输出确切接触、伸直或关节姿态。
3. **传输保真。** 原帧与最终拼图逐步对照：无非等比拉伸、增强或标签错位，步号清楚且与对应图一致。远端图像读回要使用最终布局的机器人图；此前合成蓝色矩形读回不替代此项。

检查表按每个任务、预定步及最终发送图记录通过/失败/局部不可见及原因。明显裁切、严重遮挡或无法辨认主体时不发起正式观察；自然不可见部位不伪造补全，记能力缺口。机位、布局或提示调整均留开发版本，正式确认揭示后按既有换集纪律处理。目标是足以支持过程观察的画面，不要求照片写实或新增完整渲染平台。
