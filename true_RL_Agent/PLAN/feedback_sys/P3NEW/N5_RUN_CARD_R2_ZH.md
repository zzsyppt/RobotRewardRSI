## 新数据与冻结边界

Stair 保持已核 checkpoint、任务协议、地形 suite 和正式训练资格；通过任务拥有的诊断 cohort 标识派生新的 public-dev runner seeds。旧 `v1` 保留原种子和绑定语义。新的 cohort 标识必须在卡中登记，并核对实际进入 `torch.manual_seed` 和 `env.reset(seed=...)` 的 seeds 与既有采集不同。这里改变的是同一任务域内的随机轨迹；地形并未重新抽样，不宣称新地形泛化。

Push 使用已核 checkpoint 和现有 `--eval-base-seed` 入口，新 base seed 在卡中登记；同步重建其实际 cohort、任务组合与评估绑定，保存原训练来源。不能只换输出路径或回合名冒充新数据。

两任务各预选原登记的两个 env，运行三个 seed，仍是每任务六个同步媒体回合。选 env 的原哈希排序不变；运行后按原始成功/失败标签及冻结哈希序各取一个媒体回合。缺类、不可辨或同步不符按原门处理，不补挑输出漂亮的样本。所有原始数值和原图保留。

新来源树统一纳入：Push 任务拥有的终局分类、数值导出与任务定义的来源绑定、任务拥有的视觉回合优先级，以及 Stair 诊断 cohort 入口。实验名称不进入公用层；旧冻结树不修改。实际来源清单、命令、checkpoint、cohort hash 和测试回执由机器卡引用，不在本页另造第二套身份真相。

## 观察与评阅

两任务观察者均固定为全新 `gpt-6-sol`、high、`fork_turns=none`，每个入选回合一次，共四次。使用现有生成器给出的完整盲文字、S0、定义和原图，逐图实际查看并留下访问记录；无开发历史、旧答或正式评阅结果。不再追加提示或载体尝试。精确服务端 fingerprint、usage、费用和内部图像处理不可得时明确缺失。

采用该载体的开发依据见[Stair 固定输入对照](./results/n5_confirmation_execution_r1/stair_sol_carrier_development_r1/README_ZH.md)及第一轮 Push 工程记录。Stair 的三条粗粒度形态获 root 支持，不等于独立准确率、必要过程召回或普遍模型优势；原 DeepSeek 六条观察的开发结果不被替换。

root 对全部原始观察作非盲模块核对，实际查看模型收到的全部原图及同窗定义；正文和 uncertainty 的所有命题都支持才可投递。核对在正式 facts 请求之前封存。默认报告由任务层优先同一数值代表案例、已知失败、其余回合；数值冲突仍优先。数值与视觉属于不同回合时分别标身份，不能串成一个过程。

正式评阅仍是 DeepSeek 与另一独立 SOL，两家分别对固定 40 单位作 facts/report 两阶段评阅。双方全部 facts 封存前不揭示报告。观察者与 SOL 评委同家族的相关误差保留；root 的模块票不代替独立评分。过滤前全部观察和最终投递分别验收，不靠过滤提高原始句子支持率。

## 核验范围与容量

独立程序负责冻结责任清单内的形式化派生，模型负责解释、关系、范围、必要过程和全部视觉命题；两个分母不混合。Stair 已有原档案操作数链核验；现有 Push 独立派生核验尚未独立打开 NPZ 认证全部来源操作数，也未覆盖全部姿态物理含义和 action norm 的独立重算。这些范围明确保持未核，不能以打包来源 hash 通过替代物理或语义验收。

完整资料、任务定义及每包实际来源绑定由新冻结的导出/打包入口生成；`related_v1`、输出预留 32768 固定。每份完整请求重新计量，旧 72 份请求的 tokenizer 计数只能作为工作估计。输入代理 360000、实际 HTTP 48 MiB 及原系统/输出/差异预留维持；静态能放下不能代替实际评完。发生压缩、截断或漏评如实记未完成，不能删除事实刷通过。

N.4 八个作者槽已用完。本轮只捕获生产入口的离线序列化请求，标 `offline_serialized_not_sent`，不新增作者调用、候选训练或 A/T 实验。
