## 对§5七条后续建议的处理

1. **全22策略新recorder回放：不作为首轮要求。** 先真实formal parent fca6a59c…与Gen8-A同版v3采集；需额外问题覆盖再扩池。保存成功和失败，不能只截高价值失败来冒充完整分布。
2. **从历史父子关系构建12–24案例：采纳；历史A免生成：不采纳。** 历史A输出用于了解现状。新的匹配A/T都要在相同数据可用时点、模型、预算下生成；事后v3资料不能回灌旧v2决策时点。
3. **36份formal rationale用于Phase 5：采纳为回顾fixtures。** 已取得全部原件并绑定输出；它们包含失败/未训练作者产物，不是36个RL结局。事后整理不能补成当时未登记的预测阈值或计算前瞻命中率。
4. **A基线必须有作者实际输出：采纳且已落地。** T收益既包括新增过程事实，也包括减少对已有证据和实现的误读，不能只凭描述更丰富过门。
5. **记录15-body contact force：采纳为任务层可选字段。** 现有sensor可读，包含原base所以新增14项；保持base-only forbidden。它定位受力刚体，不能定位toe/碰撞点或物体表面。
6. **删严格token门，单人＋机器验证：采纳。** 当前是工程迭代；必要的上下文/输出容量控制与事实语义审核保留。
7. **跨cell成功对照：改为补充，不作默认。** 合并seed后两策略24个cell各自都有成功；reference仅2/72个seed×cell无成功。先同cell，再跨seed分层；跨cell同stage只作说明差异的辅助类比。

## 同类问题复查

- **作者文字与奖励符号：** Push Gen4-B accepted 的lateral_brace原始值非正且weight=-1，形成非负贡献，和rationale所称penalty方向相反；后续prompt已有正的runtime贡献。此处是作者解释证据，不应改runtime乘法或回写历史候选来“修好”实验。加入A基线和Phase 3事实核查，具体源码见作者报告。
- **parent与训练初始化混淆：** 库存明确作者parent边与实际训练初始化分别存放；同权重副本去重，但相同初始化/同session不冒充独立重复。
- **缺对照被过度推断：** 重新核到cell和seed×cell，替换“高失败cell一般没有成功”的笼统结论；时间窗是否匹配待时序采集。
- **Phase 5规则过硬：** 原计划把parent跨seed离散度统一当最小容差，并把未支持预测硬分三类，均超出任务通用边界。已改为task-owned配对/效应与不确定性规则；激活、行为、得分分项记录，允许unknown。
- **计量与实验公平：** 取消严格资格不取消实际usage；历史作者输出不能代替当前A，合并9点拟合不能包装成独立误差证明。
