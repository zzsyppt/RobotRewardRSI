# Phase 3 实际实施与验收计划

日期：2026-09-24。起点：`e5c2b901`，主计划 v1.2.7。状态：本轮实现、实验及材料交付完成；人工价值门依用户决定待补。最终边界与记录见 [验收文档](ACCEPTANCE_ZH.md)。

## 本阶段要解决的问题

P2 已保存足以重算终局与部分过程的数值证据，但作者仍主要看到分数、失败比例和 ever 标志。本阶段把这些数据翻译成有限、可核查的行为描述，并检验这些描述是否帮助作者提出更有依据的修改。保留任务现有成功判据、评分、奖励权限和训练协议。

用户已明确：先交付实现、全部实验与盲评材料，人工评阅待补，价值门暂不算通过。因此工程验收、机器验收、人工评阅和早期继续门分别记录；不以模型自评代替人工，也不据此启动 Phase 4 的完整服务。

## 架构与边界

1. **档案仍是真实来源。** P2 的数值 manifest、chunk hash、checkpoint、协议与 cohort 绑定不变。新档案缺项和旧版本缺项分别记录，不能补零。
2. **任务内确定性派生。** Stair 和 Push 分别在任务 `src` 实现词条、EpisodeTranscript、BehaviorProfile、BehaviorDiff 与可操作性映射。生产不导入 PLAN。公用层不拥有台阶、脚、扰动或恢复语义。
3. **封存后再公开。** 新 public-dev phase 在封存之前生成有限行为视图，作为版本化 task evidence；公开投影仅读取回执内已有字段，不在 prompt 构建时读取 NPZ。旧 phase 不补写新字段。离线重分析另有新可用时点与来源，不伪装成旧作者当时可见。
4. **完整派生与工作集分开。** 全量时间线可由 L0 重算并导出供审阅；prompt 只保留按 stratum 的完整分母、成功/失败反证、合法父子差分和固定规则选取的少量时间线。省略数和选择规则公开。
5. **父策略来自回执关系。** generation 公共投影携带已经绑定的 parent public-dev phase，任务层核 parent checkpoint 与比较域。无父档案、源码不同或协议不同均明确缺失/不可比；on/off 不作为干预对。
6. **诊断与修改权限分开。** 每类观察映射到当前实际输入 ABI：可直接表达、仅代理可表达、缺观察、仅诊断、越权。离线未来窗口、真实地形查询、序列完成等不自动成为奖励输入；建议始终是待验证假说。

借鉴本地 Codex 的有限上下文思想：持久记录与模型当前视图分开、确定性裁剪、显示省略、计入序列化开销。此次不引入其完整历史管理、缓存或服务架构。当前本地检出 `codex` HEAD 为 `40eac3ce8a0c10cbcb9db910d529355eb2f8fc09`；具体参考 [history.rs](D:/humanoid_agent/codex/codex-rs/core/src/context_manager/history.rs:74) 中独立于模型窗口的 retained context、`for_prompt` 与原始记录视图分离，以及 437–445 行对工具输出序列化开销的计量。这里只采用边界思想，不把其鉴权/审阅或完整压缩系统移植进 RL 公用层。

## 实施单元与验收

### P3.1 有限词表与独立重算

目标：将已经验证的原型算法收敛到任务实现，补足逐身体和过程边界。

- Stair：瞬时接触开关/保持、未受力低净空、接触下快速平移、根部姿态、低进展窗口、实际立面投影锚点、forbidden manager 触发和终局。带符号位移范围供核对，不另造“回退”事件。新增阈值必须版本化且独立于 acceptance；有实际协议阈值时复用协议。旧 `any(support) → streak` 与逐身体区间分别命名。
- Push：五稳定条件的并行失守、dwell 中断、恢复达标、恢复后再失稳、相对明确扰动方向的根部平面运动。velocity 按 event，force 按完整序列最后 pulse end 对齐。
- 每个词条包含身体角色、坐标、时窗、单位、适用域、来源与未知项。没有时间戳的 history 槽不能恢复子步顺序；根部运动不能证明迈步，低净空不能证明碰撞。

验收：真实档案的终局与 P2 reducer 一致；新增描述独立核算。覆盖镜像/身体重排、并行动作、交替支撑的全局/逐脚差异、回合关闭后 padding、未达锚点、观察窗删失及旧版本缺项。仅保留能暴露语义错误的测试，不为每个字段搭建防御框架。

### P3.2 有界生产工作集

目标：真实 eval → phase receipt → generation → task prompt 全链路收到行为证据。

默认工作集：任务既有选源规则确定的反馈对象、其合法 parent、所有 stratum 的紧凑画像与成功/失败对照。Stair 选择最新有测量的对象；Push 保留既有 selected feedback trial 的身份，若其没有 public-dev，就明确缺失，不能把旧行为安到新对象上。合格参考策略的初轮也通过正式投影提供自身证据。优先典型失败、同 cell/run 成功反证，保留省略数；完整分母与成功/失败代表先于额外片段。长期保存当前 best 与最近失败两个受保护槽位的统一调度留给 Phase 5。

封存行为视图上限 Stair 8 KiB、Push 12 KiB。Stair 的来源标识与合法父差分位于视图外，实际作者工作集的总字节必须单独报告；所有包装和差分均计入 task sections 56 KiB 及原有每请求 token 上限，不能把 8 KiB 写成整个请求或工作集的大小。长期 experiment_memory 保持 14 KiB，不向每条旧历史追加时间线。具体替换/压缩段落在容量报告列明，不能只追加新证据。

验收：有/无采集和旧回执的兼容性、public-dev 与 accept/sealed 边界、受信父策略关系、无路径/私有 seed 泄露、历史重放一致性、实际有限 prompt 与来源引用一致。receipt 缺行为则显式缺失，不能临时回读档案。

### P3.3 真实档案闭合与只读审阅材料

目标：覆盖已声明支持的 Stair 两形态与 Push 两形态/两协议，建立可核查的语义案例。

复用 P2 已封存数值，优先 CPU 重算。Stair 历史 parent→Gen8 同 source_r2 的 v1 共同字段可配对；新 v2 parent/G1 用于 history 验证，不能与旧 Gen8 冒称同源码干预。Push 新 v2 仅 G1 force、Go2 velocity 有方向，其余旧 v1 明确未采集。没有已证明的 Push parent pair 时登记 missing，不拼造。

验收：输出全量派生、来源绑定、覆盖矩阵、真实实例只读时间轴、数字复核与可重跑命令。现存旧 PyBullet Stair 视频不是 P2 同源原生帧；本阶段用数值派生图核对测量语义，不能借旧视频声称当前视觉验证。若实际生产接线需要短重放，先冻结源码与资源额度再运行。

### P3.4 新 A/T 作者对照与交付

目标：冻结 12 个开发问题（Stair 6 / Push 6），两臂各 2 次新生成，共 48 次作者 episode。它们复用两份真实观察包、两个策略簇，不能当成 12 个独立观测或独立谱系。作者准入使用已有真实资格的 Go2 Stair v3 参考策略和 G1 Push velocity v2 参考策略；目录名中的奖励程序 v3 不等于 force v3 协议资格。至少两类过程问题在看输出前登记。

A 为当前反馈，T 为行为工作集。两臂相同数据时点、作者模型、奖励权限、源码访问和输入/输出/attempt 预算。历史 A 不代替新 A。源码查询和修复请求计入同一 episode 的原有预算，不另开免费调用。模型、可用资料、case 身份与选择、检查规则、盲评 rubric 在运行前冻结到机器可读卡。

本阶段预分配上限：provider US$15，GPU capacity 2 h（项目既有 US$120 / 500 h 内）；优先 CPU，无必要不训练。开跑前核现价和真实配置；实际用量与估算分别记录。不得将配额自动视为必须用完的资源。

机器验收：引用、数值、奖励符号/修改权限、输出合同、预算、公平性及可复现性。人工盲评包隐藏臂名并打乱，提供原始时间轴和固定 rubric，支持不确定，不自动填入结论。

本次事前选择主计划的质量收益路线：零全局硬错误、事实支持率至少 95%、至少两个预登记过程类别出现决策相关改善且授权/可检验性不退化。主计划允许的“质量不退化而费用降低至少 20%”路线本次不采用，费用只作描述，不能在看过结果后切换路线通过。机器结构检查不等于人工事实支持率。人工未完成时继续门为 `pending_human_review`，不写 PASS。

## 完成前逐项审计

- 词条定义、原始来源、完整分母、同时事件、缺失/删失、身体/坐标/时钟是否一致。
- 是否真正从生产 producer 接到作者，是否有仅脚本可用的旁支。
- 是否有同一事实在多处重算、旧原型 import、任务语义进入公用层、重复实现或临时补丁。
- 合法父子比较是否核源码/协议/cohort，是否误把描述差异或终局共现写成因果。
- token/bytes、源码查询、重试和实际费用是否闭合；A/T 是否同预算。
- 每项结果明确工程已通过、机器已通过、实验已完成、人工待补或未达门，不混成一个“完成”。
