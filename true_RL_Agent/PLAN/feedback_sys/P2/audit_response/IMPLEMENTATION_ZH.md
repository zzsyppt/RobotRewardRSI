2. Push 数值 profile v2 增加世界系平面速度与 reset 相对位移向量；原范数是实际判据操作数，保留并检查向量一致性。任务内共享最终分类，独立 reducer 继续校验时序与 dwell。
3. 训练采样 v2 保留最多 24 步 × 16 环境预算，在训练三个等分阶段各分散取最多八点，early 首点固定第 1 步作为启动锚点，避免早期失败完全没有原始样本。完整索引留在私有档案，作者覆盖摘要不扩张。全程聚合、首个非零时刻及训练因果诊断不在本次范围。

5. 总账以配对报告确定验收角色，补全两条手工运行的来源证据，保留启动命令未记录的事实；更正 RSS 描述。指定生产 Stair 回放入口，历史 PLAN 工具只作历史复现。
