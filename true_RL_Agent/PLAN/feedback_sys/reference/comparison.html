02 · Constrained agent

四阶段把观察与注册解耦

代码约束决定每个阶段必须完成的观察与注册动作，使不同模型在更接近的路径上完成任务，并保留每一阶段的中间证据。

STAGE 00

ROI 预处理

围绕手部区域与交互物体区域裁剪视频，产出后续阶段使用的 cropped.mp4。

STAGE 01

面向物体切分

强制完整调用 watch_video，再用 register_object_oriented_clip 注册出现手部交互的物体片段。

STAGE 02

手部区域与物体识别

并行截取中间帧定位手部 ROI，结合完整帧与局部图像，用单帧证据识别交互物体。

STAGE 03

动作注册

再次强制完整遍历视频，在前序识别结果上使用 register_action 注册全部手部动作。
