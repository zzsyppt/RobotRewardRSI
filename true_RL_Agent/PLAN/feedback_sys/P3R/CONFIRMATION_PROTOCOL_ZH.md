## 资料与选择

继续使用已合格Stair Go2与Push G1 velocity父本，另采一份完整公开诊断包：Stair864、Push192回合。Stair使用新task-owned `public_dev_diagnostic_v1` seed namespace；Push使用此前未使用的 `eval_base_seed=1500000000`，并在执行前确认进入cohort绑定及实际采样。两者都是同策略的新回合，不是新谱系；仅允许同策略局部确认。没有候选训练、sealed评估或新的资格授予。

原P2/P3/R.0的所有轨迹、画面、评语及新实现的开发重算均属开发资料。新包的行为报告可由正常生产路径写入，但标注者先只收原始档案、完整曲线和任务定义；看完并封存原始事实清单后才开放行为报告。作者始终不能接收确认标签、评语、人工整理答案或额外画面说明。

选择不依赖新报告、规则阳性或作者输出。稳定次序为`SHA256("p3r-confirm-v1|task|run|env")`升序，id用于打破同hash。使用原采集终局记录判断成功/失败，不使用新reducer标签选例：

- Stair：六个事前焦点stratum各选一个失败回合，优先该stratum数量最多的原始primary reason，平手按标签字典序；在其同cell/run选一个成功反例。无失败时选两个不同成功回合；相同cell/run无成功则依次同cell其它run、同stratum其它cell。匹配级别如实登记。共12个不同回合；不足不从其它焦点悄悄补齐。
- Push：low/medium/high/repeated各选一个失败与一个成功，优先该stratum最常见failure label及同run成功；无失败则两个不同成功。另在medium、repeated各选一个尚未入选的失败和成功（同一排序与匹配原则），共12个不同回合。样本不足记INCONCLUSIVE。
- 完整回合从首个有效样本至终局均提供；额外固定0%、25%、50%、75%、100%位置检查。确认必须确实覆盖成功、失败及规则阴性区间；若所选池没有某个困难类别，列覆盖缺口，不凭空称已验证。

## 先验问题与必要事实

12个作者焦点及过程类别固定于 `confirmation_design.json`，沿原研究问题改用新来源，所有焦点接收同一任务的默认报告；不做按问题手工筛例。Stair六个stratum：前沿、粗糙表面、高度、踏面、联合几何、阶段组合；Push四个强度组、全体及第一logical run。

完整回合的原始标注按下列有意义的事实束切分，不按每帧/每个重复数字增加分母：

| 任务 | 全程需要核对的过程事实 |
|---|---|
| Stair | 终局及范围；前进、最大回退和主要低进展时段；带符号姿态及翻转方向、与终局的先后/重叠；同一绑定脚的无载低运动时段及其与低进展关系；成功中也存在的同类过程；可采数据仍不能判定的物理解释 |
| Push | 实际执行与未执行事件；注入锚点、首个事后观测及峰值顺序；每次事件相对锚点的运动变化；哪些稳定条件先后超限、主要连续时段；首次驻留、后续再失稳、窗口末及终局之间的关系；观察截断与缺观测 |

主要时段不是“所有细小阈值过线”：事前以任务现有持续阈值判条件段；对新增连续量需记录最大变化及其时间、终态，并由标注者从全程指出会改变失败解释的明显不同阶段/新组合。有原始依据而新词表无法表达的主要过程仍计漏检。解释性的“打滑、僵死、腹部撞击、踝策略、训练根因”等若缺足够观测，登记缺口；不得因词表包含相似代理量就判已测到。

默认报告及最终请求单独以每个焦点问题为单位，原始池需要回答：①完整样本分母与结局；②主导失败形态中哪些测量过程常见、哪些并不常见；③相容成功反例是否也有该过程（无匹配则明确）；④至少一个有原始定位依据的主要过程关系/关键量，可为有分母的组级统计，不强制每题独享个体时间线；⑤会限制改动判断的缺观测或采样范围。无失败的焦点回答成功与规则阴性，并明确缺失败证据，不虚构主导失败。标注者从原始池先填这五束的具体答案、必要项和不可回答项，不看默认报告决定什么“必要”。

纯数值profile仅对现有数值支持的事实计算召回；仅视觉可见和真实未采样项分别完整记录为能力缺口。主动声称这些缺证据观察仍计不支持。本文不新开可选视觉采集。

## R.3 判分

沿详细计划：完整回合逐回合宏平均事实支持率≥95%，关键过程召回、时段/部位定位各≥90%；默认报告及实际请求按问题宏平均支持率≥95%、必要事实覆盖≥90%。两任务分别达门；每类成绩及困难类别分开列。身份/来源/权限硬错误或影响动作判断的系统性语义错误一票否决，不能靠容易的数值平均掩盖。

固定容差：浮点数为原始量的1e-5绝对误差或明确展示精度的半个末位单位，取较大值；比例的分子分母必须正确。精确事件定位误差≤1个控制步（当前20ms）；区间两端均≤1步，或交并比≥0.8且未把重复出现合并成虚假连续/单次因果链。部位必须一致，不允许以任意脚替换同一脚；同帧不等于严格在前。采集定义不同的锚点不能用时间容差掩盖。

每项主张记supported / contradicted / unsupported / unanswerable，事实支持率为supported除以所有事实主张（不把unsupported排出）；真正不可回答的问题明确表达缺证据可记范围正确，但不能拿它替代可回答事实。召回以原始先验清单为分母，空白、无谓拒答和裁剪遗漏算漏。机器复算与模型语义评阅分别记录，不能把逐字段相等自动改称语义PASS。

任何按新结果修改规则、选择、压缩、提示或判分主规则的行为，会使整包转开发。该包不得继续作为最终R.3/R.4确认资料；下一包需要另行冻结。错误在采集/身份层则如实失败，不拿同seed重采充当独立新证据。

## R.4 共同设置与改善判定

仅R.3通过后执行12案例×A/T×2=48个机会。A/T同父本、同新公开cohort、同as-of、同模型high/65536、40k输入、最多5次provider尝试及2次源码请求。A只移除自动行为子树，其它非行为反馈、公共提示、静态修复及source权限相同。新公开诊断不能替代旧资格或与旧sealed拼出新资格；历史成绩如出现须明确属于原资格。

case顺序固定随机种子2026092904；每case的第一次随机A/T顺序，第二次反向；两次都计入，不挑好的一次。匿名提案随机种子2026092905；评阅使用用户授权`model_review`，校准只用R.0开发资料。评阅者先核语义与代码，再核实际输入支持；输入样式可能暴露条件，不能称完全盲化。

事实切分以独立可证伪的主张为单位，数值、范围、时间关系及代码行为不同则拆；同一主张换词重复只计一次。候选源码docstring中的论断也计入；未训练干预效果单列为假说，不把合理猜测算已证事实。观测矛盾和源码/算术矛盾为关键误判；未知机制没有被直接反驳时记不可判，不强行计硬错。全部48机会均保留分母；无候选无法贡献改善，不能以事实数0计满分。

每案例的两次生成共同汇总：关键错误数/事实数、每回答事实支持率、必要证据正确使用束数、权限、机制—代码一致性与可证伪预测。该案例出现改善需T两次合计关键误判少于A且必要证据正确使用不下降，或必要证据正确使用多于A且关键误判不增加；同时不能出现新增同等或更严重关键误判。必要证据只是抄数字不算用于改动，须明确把所见关系连接到提出的干预或证据不足决定。只报告最好提案不能构成案例改善。

沿原严格门：T事实支持率微/宏均≥95%，两任务分别通过；至少两个预登记类别、每类至少两个不同案例改善，且每个任务至少有一个达标类别；授权、可检验性、机制—代码一致性不退化。同观察包的6题不是6个独立环境。质量收益失败就按原退出表记录，不再在当前集加样本或改走省钱路线。
