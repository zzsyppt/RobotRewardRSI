# Stair 开发证据独立审查记录

日期：2026-09-29。范围仅限 `stair-01`、`stair-03` 的 Tc-num / Tc-vis、`curate_stair_raw.py`、`curate_stair_probe.py` 及其绑定的 P3 数值与录像材料。本记录不构成人工盲评、作者建议评分或价值门通过。

## 已核对的事实

- 以冻结的 `P3/results/author_final_bundle/author_blind_review/reviewer/evidence-stair.json` 和 `P3R/results/stair_raw_independent.json` 为依据，完成 45 项计数、代表身份、姿态公式和文件 hash 核对，均通过。各结果组分母与事件计数一致，代表 episode 的 cell、终止原因和步数一致。
- 区间时长按材料已声明的含首末控制步计数计算，即 `(end-start+1)*0.02`；该值不是首末采样时间戳之差。原始位置是世界轴方向减去环境原点，未被当作楼梯表面净空或 reset 后位移。
- 四元数为 wxyz；抽取的身体前轴/上轴世界 z 分量与输出的 roll/pitch 一致。四足顺序与冻结绑定中的 FL、FR、RL、RR 顺序一致。
- 查看了 `g64_r1_zoom.png` 与 `g156_r1_zoom.png`。图片帧标签和 Tc-vis 声明一致；对应 sidecar 的 checkpoint、槽位、终止原因和终止步数吻合。e64 数值终止步为 426，录像显示到 425；e156 为 232，录像显示到 231。没有将终止前画面宣称为实际碰撞点证据，也没有宣称逐步重放完全一致。
- e64 的侧向/后向翻转、末段身体下面与抬起的足朝向相机，有画面支持。e156 所示采样帧中仍有腿部屈伸且身体多次接近楼梯表面，没有可见的整机翻滚；这些是有限视角的视觉观察，不是精确碰撞、摩擦或控制意图判断。Tc-vis 交给作者的是这些观察文字，不含图片像素。

## 已落实的文字与结构修正

1. 保留短暂 tilt 区间，但明确 `confirmed=null` 表示不足 10 个连续步；持续 tilt 的计数另要求达到 10 步。
2. 低进展明确为“完整 0.5 秒窗口内最大 root x 减去窗口首值低于 0.02 米”，不是首末净位移或整机静止。
3. 低足点的连续条件明确允许不同脚逐步交替满足；无瞬时支撑仅表示四足瞬时净接触力均未越过 1 N，不能单凭它认定物理悬空。
4. 同 cell/run 的成功组已去重，每组保存一次成功统计和分原因失败统计；没有靠删除分母来缩短输入。
5. 明确 e48 是 level4 的 timeout 补充例，不能当作 level5 的 e64/e69 匹配对照。
