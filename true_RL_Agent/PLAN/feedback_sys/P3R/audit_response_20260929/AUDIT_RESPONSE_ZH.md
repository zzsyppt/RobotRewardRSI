### 001：原零硬错不成立

同意审计指出的代码矛盾。候选声称任务用于驻留判断的直立区域保留完整阻尼，但实现为 `keep = 1 - 0.75 * clamp(sqrt(roll² + pitch²) / 0.4, 0, 1)`。在任务姿态带内，roll=0.2、pitch=0 时 keep=0.625；两个轴均为 0.2 时约为 0.46967。精确零姿态确实保持原阻尼，不能代表整个驻留姿态带。

独立标量检查使用带内姿态和带内速度即可反驳这条声明；不需假定实际轨迹发生过该状态。按原规则，主评裁定该项行动相关性降为 1，机制对应仍可为“是”，至少一处可复核硬错误，不能贡献达标。另有“57 次总中断”与“每回合少于 57 次”的分母混用，单列预测基线问题，不把未来预测自动算成已经发生的错误观测。

### 022：不接受仅凭“预测不够细”自动降分

原冻结规则没有要求必须预测具体俯仰分布或完成因果辨别实验。候选同时引用成功/失败中的鼻上仰，提出仍待验证的解释，并以 forbidden_contact 和 mean progress 不变作为反驳条件；mean progress 是过程量。主评按该旧口径保留 AR2 的解释，注明这是较弱的联合反驳条件，无法单独辨别所提机制。审计的 AR1 仍作为评阅分歧保留；不能用新偏好追改旧门。

上述只是两项裁决，不是全体 32 项的重新验收。若仅替换 001 并保留其他原分，Tc-num 从两个案例降至一个，Tc-vis 仍为三个；若同时采用审计对 022 的降分，Tc-vis 仍有两个案例。这两个局部重算都落在“仅 Tc-vis”一行，但不再将它发布为新的无争议全体门结论。

### 全类别复核还发现什么

为避免掌握映射的一方只挑过门项复核，两个独立子代理分别按同一类别检查了全部 32 项，均没有读取旧评分、变体映射或本次审计分数。主评收尾不是盲审。结果保存在本目录，不能把局部类别无错误当作全局零错误。

- **保留区域、条件生效及成本变化声明：**确认 005、007、008、011、013、025 六项有代数矛盾，已保存源码摘录和可重复 CPU 反例。包括软门控没有真正关闭、尾部斜率下降不等于总成本下降、实际饱和条件与文字不同。001 的任务驻留语义由主评结合明确句子裁定。没有观察数据支撑的历史保持声明不强判为已发生的轨迹错误。
- **过程预测类别：**14 项有过程预测（部分带范围缺陷），13 项仅有结果预测或设计意图，5 项存在边界歧义。这不是 AR2 数量。018、023 原已计达标，但其显式预期主要是结果指标；是否将假说段的行为含义视作预测仍需统一解释。因此不靠只修 001/022 再包装一个确定的全体新分数。

这些都是作者提案/评阅层问题，不应因此在通用反馈层加入任务专用奖励规则或一个自动代码因果证明器。已停下的研究门不值得继续用更多模型投票追求整齐判分；原结论记“有分歧，数值有效声明撤回”即可。
